# Agent 操作手册：把任何一个"局"跑成一份可执行的决策报告

> 目标读者：没有读过原著的 agent。
> 读完这一篇 + `SCHEMAS.md`，你就能独立把一个新局实例化、跑出数字、拿到动作清单。
> 全程只需要一个命令：`python3 scripts/gt/qixia_gt.py`。

---

## 一、先记住三条铁律

1. **先规则，后收益，最后才谈策略。** 跳过规则侦察去算收益矩阵，等于在错误的棋盘上下棋。
2. **每个结论必须带"失败条件"。** 工具每条输出都含 `fail_if[]`；如果一条策略没有失败条件，说明你还没建模。
3. **数值是假设，结构才是知识。** 原文只给规则文本、不给收益数字。参数错会结论错，所以每次都要写下参数从哪来。

## 二、标准作业流程（7 步，约 5 分钟）

### 第 1 步：写局面摘要（自然语言，不用算）

把规则文本、你已知的隐藏规则、裁判是谁、赌注是什么，全部塞进一段 `summary`。
**不要在这步做判断**，只需要覆盖信息。

### 第 2 步：跑一次 `audit`，让工具告诉你"这是哪类局"

```bash
python3 scripts/gt/qixia_gt.py audit --file cases/gt/situation_interview_room.json
```

输出会列出命中的模型（按关键词命中数排序）+ 哪些模型参数缺失。
这一步的价值：**它经常指出你没想到的模型**（比如你以为在玩心理战，其实在玩机制设计）。

### 第 3 步：按命中顺序逐个补参数，逐个跑

每个模型缺什么参数，报告里会写"参数缺失：… 下一步：运行 `xxx` "。
按 `SCHEMAS.md` 把参数填进 `situation_*.json` 的 `gN` 段，再跑一次 `audit`，直到所有命中模型都有结果。

### 第 4 步：读 `gaps[]`——这是破局点清单

`gaps[]` 汇总了三类东西：
- **规则未定义处**（平局/时限/解释权/隐藏权限）→ 可直接利用，也可要求补丁换取让步；
- **激励不相容处**（说真话不划算）→ 对方一定会说谎，按说谎后的行为布防；
- **参数缺失处** → 你还有信息要查。

### 第 5 步：把 `action` 排序成一条时间线

模型的 `action` 是"单步最优"。真实执行要排顺序：先做**不可逆性最低**的（试探/取证），再做**不可逆性最高**的（下注/赌命/公开立誓）。

### 第 6 步：写反击预案

对每个模型，`counter` 字段给的是"对手会怎么反制我"；把它反过来读，就是"对手若这样打，我该怎么应"。

### 第 7 步：落地校验

```bash
python3 scripts/gt/qixia_gt.py selftest        # 引擎自身没坏
sh scripts/gt/run_cases.sh                     # 案例库全部可复现
```

## 三、完整示例：面试房间（新人第一局）

### 3.1 局面

醒来在面试房间；规则由生肖口头/广播给出；违规即抹杀；对手可能是普通参与者，也可能是生肖安排的协助者；允许赌命。

### 3.2 跑 audit

```bash
python3 scripts/gt/qixia_gt.py audit --file cases/gt/situation_interview_room.json
```

识别结果（命中数降序）：**G2 贝叶斯 → G6 逆向归纳 → G1 囚徒困境 → G4 机制审计 → G3 信号 → G5/G9 → G12 元博弈**。

### 3.3 逐模型结论（报告原文摘要）

| 模型 | 工具结论 | 关键数字 | 动作 |
|---|---|---|---|
| **G2** | 后验把"对手是协助者"从 0.30 抬到 **0.576**，但仍在中间区 | LR=6/19，EVPI=28/33≈0.85 | 选"保留底牌并试探"（EV≈2.42；全力压榨 EV≈−3.64） |
| **G6** | 生肖的"违规即抹杀"是**可信**威胁（执行成本低、有机关权限） | SPNE 值 (我 0, 生肖 2) | 按规则走，别拿"他其实不会执行"去赌 |
| **G1** | 房间内是**单次**囚徒困境 | δ*=0.5，单次 → 唯一均衡 (D,D) | 先背叛；若必须合作，先制造"还有下一次"或抵押品 |
| **G4** | 规则结构有 4 处 DSIC 违反 + 2 处 IR 违反 | 效率 15/17≈0.88 | 规则在奖励说谎 → 预期对手会谎报，按谎报后的分配布防 |
| **G12** | 元博弈风险 **9/9**（目标他定、结算他可改、无退出选项） | — | 先争"规则解释权/退出权"，否则赢了也归零 |
| G3/G5/G9 | 参数缺失 | — | 需要具体动作/收益/资源数才能结算 |

### 3.4 综合动作序列（把单步最优排成时间线）

1. **先用低成本动作取证**（试探、问一个"元问题"）——不可逆性最低；
2. **同时把话说死**：要求生肖把口播规则写成可确认的形式（把 G4 的漏洞变成对自己有利的补丁版本）；
3. **按 G1 的单次结论准备背叛**，但**不要先动手**：先让对手暴露动作（他先动 = 我获得信息）；
4. **保留"底牌"**（未被观测的资源/信息），因为 G2 的后验还没集中到可以押注；
5. **全程为 G12 留后手**：任何承诺都不要给到"赢了也没法自保"的程度。

### 3.5 这份报告的元结论

> 面试房间真正的胜负手不在"猜对手想什么"，而在**规则解释权**：G4 的漏洞 + G12 的结算权，
> 决定了 G1 的收益矩阵长什么样。**先改矩阵，再玩矩阵。**

## 四、快速选择模型的判定树

```
局面进来
├─ 我拿到规则原文了吗？ ── 没有 ──> 先侦察（G4 的 checklist 前半段），别算
└─ 有
   ├─ 有先后顺序、有威胁/承诺？ ────────────> G6（逆向归纳）
   ├─ 已经投入很多，要不要继续？ ──────────> G7（沉没成本）
   ├─ 双方能同时选、有明确收益矩阵？
   │    ├─ 一方有占优动作、单次 → G1
   │    ├─ 没有纯均衡 → G5（混合策略）；下注类问题再叠 G8
   │    └─ 有多个纯均衡 → G5 + G10（协调/共同知识）
   ├─ 我需要"证明自己"或"看穿对方类型"？ ──> G3（信号）；我是设计方 → G11（甄别菜单）
   ├─ 我可以先设计分配/规则/赔付？ ────────> G4（机制）+ G9（概率分配）
   ├─ 多方要对表行动、信道不可靠？ ────────> G10
   └─ 以上都赢不了，或者"赢了也没用"？ ───> G12（谁在结算？）
```

## 五、自己写一个新局面（模板）

```jsonc
{
  "name": "新局名",
  "summary": "规则原文 + 隐藏规则 + 裁判 + 赌注（自然语言，越长越好）",
  "keywords": ["规则", "赌注", "隐藏"],
  "g4":  { /* mechanism 段：谁分配什么、谁付什么 */ },
  "g6":  { /* backward 段：有顺序的决策 */ },
  "g1":  { /* pd 段：收益矩阵 */ },
  "g12": { /* meta 段：目标是谁定的 */ }
}
```

写完之后：

```bash
python3 scripts/gt/qixia_gt.py audit --file cases/gt/my_situation.json --out reports/gt/my_situation.md
```

**不需要每个 `gN` 都填**：没填的会以"参数缺失 + 下一步命令"的形式出现在报告里，这本身就是一份待办清单。

## 六、常见卡点与解法

| 卡点 | 现象 | 解法 |
|---|---|---|
| 收益写不出来 | "我不知道对方拿走 X 值多少" | 先把收益写成**序数**（谁多谁少），只需要不等式就能判结构（PD/胆小鬼/协调） |
| 树画不完 | 分支爆炸 | 只画**最后三步**（终局结算层），前面的用"收益向量"折叠 |
| 类型太多 | 信号博弈枚举爆炸 | 先二分（强/弱、真/假），跑通再细分 |
| 结论和直觉冲突 | 工具说"继续"，我想止损 | 检查是不是落进**陷阱区间**（`p* ≤ p < p_lookback`）——那是情绪 vs 理性的分界线 |
| 结论模棱两可 | 分离/混同都对 | 说明信号成本结构没设计好 → 转 G11 改成本，或承认只能靠 G4 的事后惩罚 |
| audit 选的模型太多 | 一堆"参数缺失" | 正常。按 `gaps` 的优先级补：G4 → G6 → G1/G5 → 其他 |
