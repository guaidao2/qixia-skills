# G11　甄别合同菜单（信息租金与扭曲）

**标准模型**：Screening Menu / Information Rents & Distortion
**脚本入口**：`python3 scripts/gt/qixia_gt.py screening --file <json>`　（`--json` 输出机器可读结果）
**原书锚点**：生肖飞升对赌合同（晋升=自证）；极乐钱庄三层结构（博彩/彩券/存款）；地羊「四情扇」花道买扇
**何时用**：我要给不同类型的人提供不同选项，让他们自选并暴露类型 / 对手给我一份『多档合同』，要我选一档 / 需要算：为了让人说真话，我必须让出多少信息租金

## 1. 形式化定义
**Mussa–Rosen 甄别模型**：类型 $\theta_H>\theta_L$，先验 $p=\Pr(\theta_H)$，效用 $u=\theta q-t$，成本 $c(q)=q^2/2$。

最优菜单：
$$q_H=\theta_H,\qquad q_L=\theta_L-\frac{p}{1-p}\,(\theta_H-\theta_L)$$
$$t_L=\theta_L q_L,\qquad t_H=\theta_H q_H-(\theta_H-\theta_L)q_L$$
高类型的信息租金 $\Delta\theta\cdot q_L$；低类型的数量被**向下扭曲**；低类型 IR 绑定（零租金）。

**放弃条件（shutdown）**：$q_L\le0\iff \theta_L\le\frac{p}{1-p}\Delta\theta$ —— 此时只服务高类型最优。

**IC 绑定现象**：标准解下 $u_H(q_H,t_H)=u_H(q_L,t_L)=\Delta\theta\,q_L$（高类型无差异），
所以实际执行时必须再给一个 ε（降价或附赠可撤销权益），否则高类型会随手选低档。

## 2. 故事 → 模型 的映射表

| 故事要素（已确认的规则/情节） | 模型符号 | 建模说明 |
|---|---|---|
| 生肖对赌合同的「多档承诺」 | 菜单 $(q,t)$ | 「晋升名额/资源」= q；「要押上的东西」= t |
| 极乐钱庄存款 ±10% | 绩效型支付 | 总红 +10%／总绿 −10%／总白 0 是典型的状态依赖支付 |

| 「低档服务差」 | 数量扭曲 | 不是服务差，是刻意设计来挡住高类型伪装 |
| 齐夏选低档装弱 | 伪装套利 | 只要能伪装，租金就被他拿走（逆向选择） |

## 3. 决策流程（照做即可）

- 1) 写出两类类型的估值与成本，确认单交叉（高类型的边际效用更高）。
- 2) 设计菜单 {(q,t)}：低类型拿被扭曲的数量（低于最优）、零租金；高类型拿最优数量、付出信息租金 Δθ·qL。
- 3) 检查 IC：高类型不想装低类型、低类型装不起高类型。
- 4) 检查 IR：低类型恰好无差异（绑定），高类型有正的租金。
- 5) 算扭曲量：qL = θL - (p/(1-p))·Δθ；若 ≤0 则放弃低类型（shutdown）。
- 6) 作为被甄别方：识别哪一档是『为零租金设计的陷阱档』，以及能否伪装成低类型套利。

## 4. 判定 checklist（任一不过 → 不要下注）

- [ ] 菜单的每一档是否都满足 IR？（不满足=逼人退出或摆烂）
- [ ] 低档的数量扭曲是否被我误当成『服务质量差』？那是有意设计的筛选器。
- [ ] 我伪装成另一类型的成本是否低于获得的差额？
- [ ] 是否存在『选高档但只付低档』的执行漏洞（G4）？

## 5. 危险信号 / 反制 / 失败条件

**危险信号**：合同里高档选项附带不可逆义务（自杀条款）；『免费试用』档的退出成本极高

**反制**：
- 自建菜单反向筛选对手
- 用可验证凭证替代自述类型
- 对高档附加可撤销的保证金而非不可逆义务

**失败条件（踩中任意一条=这套策略会送你死）**：
- 给低类型留了正租金 -> 所有人都装低类型
- 高档义务不可逆 -> 没人敢选，菜单失效

## 6. 建模假设（不可外推的部分）

- 成本函数 $q^2/2$ 与两类类型是标准教科书设定；原文的「资源/名额」不是连续量，实际需离散化。
- 假设菜单可执行（高档的义务能被强制履行）；若高档含不可逆义务（自裁条款），高档实际上无人可选 → 回到 G4 的 IR 失败。
