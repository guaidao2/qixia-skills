# G7　沉没成本与承诺升级（escalation）

**标准模型**：Sunk Cost Fallacy / Escalation of Commitment / Burning Bridges
**脚本入口**：`python3 scripts/gt/qixia_gt.py sunk --file <json>`　（`--json` 输出机器可读结果）
**原书锚点**：第250章 沉没成本；第617章 失算；十年前的「天秤游戏」；七年生肖之路；第886章 无法赌命
**何时用**：已经投入巨大成本（时间/道/队友/记忆），继续 or 放弃 / 对手已投入巨大成本，可被诱导向继续加注 / 需要把『已投入』转化为可信承诺

## 1. 形式化定义
沉没成本 $S$ 不进入边际决策：
$$a^\*=\arg\max_{a}\ \mathbb{E}\big[u(a)\mid \text{当前状态}\big]\quad\text{（与 } S \text{ 无关）}$$

继续 vs 放弃：$\text{EV}_{\text{cont}}=pV-c$，比较 $q$（保留收益）：

$$p^\*=\frac{c+q}{V}\quad\text{（真临界胜率）},\qquad
p_{\text{lookback}}=\frac{S+c+q}{V}\quad\text{（把沉没成本算进去的伪阈值）}$$

$p^\* \le p < p_{\text{lookback}}$ 称为**陷阱区间**：理性应继续，但情绪会让人放弃；
$p<p^\*$ 时任何「已经投入这么多」的理由都是谬误。

**消耗战（war of attrition）**：双方各付成本率 $c$、奖赏 $V$，对称均衡的退出风险率 $h=c/V$，
期望持续时间 $=V/c$ —— 拖延的期望成本等于对手对奖赏的估值；估值低者先退。

| 故事要素（已确认的规则/情节） | 模型符号 | 建模说明 |

## 3. 决策流程（照做即可）

- 1) 先把 S 从决策里划掉：它无论如何都收不回来，**不进入边际决策**。
- 2) 只算增量：EV(继续) = p·V - c；与 q 比较。
- 3) 算临界胜率 p* = (c+q)/V：低于 p* 就该立刻止损，无论此前投入多少。
- 4) 反过来利用对手的沉没成本：让对手先投入（门票/抵押/公开承诺），再改变规则或提高价码，他会因为不甘心而继续加注。
- 5) 若 S 可以转化为承诺（烧船/毁钥匙/公开立誓），则 S 不是浪费，而是买了『不可反悔』的可信度（G6）。

## 4. 判定 checklist（任一不过 → 不要下注）

- [ ] 我继续的理由里，有多少是『为了不浪费已经投入的』？这部分必须剔除。
- [ ] 若今天是我第一次面对这个局面（S=0），我会投入吗？
- [ ] 对手是否在利用我的沉没成本加价？
- [ ] 止损的信号是否已经出现但我拒绝承认（第617章 失算）？

## 5. 危险信号 / 反制 / 失败条件

**危险信号**：『已经走到这一步了』；『再撑一次就能翻盘』；加注额度越来越大而胜率没变

**反制**：
- 预先设定硬止损线并公开（外部约束）
- 把决策权交给未投入的第三方
- 要求对手先亮出他的沉没成本（谁更不敢退）

**失败条件（踩中任意一条=这套策略会送你死）**：
- 为了面子/执念继续加注 -> 归零
- 对所有人使用同一套沉没成本诱导 -> 遇到真能止损的人被反杀
- 把可回收资产当沉没成本销毁 -> 失去退出选项

## 6. 建模假设（不可外推的部分）

- S/c/p/V/q 都是抽象单位（见 case 的 note 字段）；原文没有给出量化收益，本模型只保证「结构」正确。
- 假设收益可货币化比较；若奖赏是非线性效用（如「妻子复活」），需要把 V 换成效用差，临界值会移动。

## 7. 与其他模型的联动
G7 判断「该不该继续」；G6 判断「继续能不能变成可信承诺」；G12 判断「赢了之后这个奖赏是否真实」。
