# G1　囚徒困境与重复博弈

**标准模型**：Prisoner's Dilemma / Repeated Game (Folk Theorem)
**脚本入口**：`python3 scripts/gt/qixia_gt.py pd --file <json>`　（`--json` 输出机器可读结果）
**原书锚点**：第278章 囚徒困境；第567章 骗亦是信；地狗「送信人」奸细阵营；极乐博彩「胜/负/杀」对赌
**何时用**：存在「合作对双方都好，但单方背叛更划算」的收益结构 / 对手是理性且只结算一次 / 或会长期重复相遇 / 需要判断要不要先合作、要不要惩罚、惩罚多久

## 1. 形式化定义
双人正规型博弈 $G=(A,B;u_1,u_2)$，$u_i\colon A\times B\to\mathbb{R}$。

**囚徒困境的判别式**（合作 C / 背叛 D）：记

$$T=u_1(D,C),\quad R=u_1(C,C),\quad P=u_1(D,D),\quad S=u_1(C,D)$$

- 结构条件：$T>R>P>S$，且 $2R>T+S$（后一条不等式保证「重复合作」优于「轮流背叛」，否则不是 PD 而是别的结构）。
- 一次性博弈：$D$ 严格占优，(D,D) 是唯一纳什均衡；合作承诺不可信（cheap talk）。
- 无限重复（贴现因子 $\delta$）：冷酷触发策略支撑 (C,C) 当且仅当

$$\delta\ \ge\ \delta^*=\frac{T-R}{T-P}$$

  直觉：右侧 = 「一次性背叛的额外收益」÷「永久回到 P 的总损失」。
- 有限 $N$ 次重复：逆向归纳 → 最后一期背叛 → 全期背叛（连锁店悖论）。
- 保底线（我方 maximin）：$\max_{p}\min_j \sum_i p_i u_{ij}$，用于设定「最坏情况仍可接受」的止损线。

| 故事要素（已确认的规则/情节） | 模型符号 | 建模说明 |
|---|---|---|
| 两类动作：合作/背叛 | C / D | 原文不给数字，收益序由世界规则决定（夺道=高 T） |

## 3. 决策流程（照做即可）

- 1) 把局面写成 2x2：双方各有 C(合作/守信) 与 D(背叛/夺道) 两个动作。
- 2) 判 T>R>P>S 是否成立，且 2R>T+S —— 成立才是真囚徒困境。
- 3) 若一次性：唯一纳什均衡是 (D,D)，任何「我们合作吧」的口头承诺都是廉价的。
- 4) 若重复：算临界贴现因子 δ* = (T-R)/(T-P)；δ≥δ* 时触发策略可支撑合作。
- 5) 选触发策略：针锋相对(TFT) / 冷酷触发(Grim) / 以牙还牙+宽恕；对手背叛一次的反制速度要快于其收益回收期。
- 6) 若对手不知道 δ（信息不完全），用「可观测的惩罚承诺」把 δ 变成共同知识（公开处刑、公开撕票、公开立誓）。

## 4. 判定 checklist（任一不过 → 不要下注）

- [ ] 是否确认过 2R>T+S？很多『囚徒困境』其实是猎鹿/胆小鬼博弈，策略完全相反。
- [ ] 对手的 T（背叛收益）是否被我低估？在他眼里背叛可能是零成本。
- [ ] 这场博弈是单次还是重复？对方是否认为『没有下一次』（末世/必死局常被判为单次）。
- [ ] 我的惩罚承诺是否可被观测？不可观测的惩罚 = 不存在。
- [ ] 合作是否有『可被单方摧毁的抵押品』（人质/共同资产/把柄）？

## 5. 危险信号 / 反制 / 失败条件

**危险信号**：对手主动提出合作且拒绝立下可执行抵押；对手反复强调『这是最后一次』；规则允许杀人夺道（背叛收益≈无限）

**反制**：
- 制造可观测的重复关系（把一次性博弈改写成重复博弈）
- 先手自缚：公开销毁背叛选项（销毁钥匙/交出人质）
- 提高背叛成本：让第三方见证并承担惩罚义务

**失败条件（踩中任意一条=这套策略会送你死）**：
- 误把胆小鬼/猎鹿当囚徒困境 -> 该强硬时合作，被杀
- 单次博弈中先合作 -> 被一次性收割
- 惩罚承诺不可观测 -> 对手理性选择背叛

## 6. 建模假设（不可外推的部分）

- 收益数值（3/0/5/1）是抽象单位，只用于展示结构，不是原文数据；原文没有给出数值收益。
- 「重复」性质取决于对手是否相信还有下一轮——这是可被操纵的信念（齐夏常用手法：伪造『没有下一次』）。
