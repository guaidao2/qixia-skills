# G8　诈唬频率与底池赔率（阈值/混合）

**标准模型**：Bluffing Frequency, Pot Odds, MDF & Alpha
**脚本入口**：`python3 scripts/gt/qixia_gt.py bluff --file <json>`　（`--json` 输出机器可读结果）
**原书锚点**：朔望月（德州扑克化）；极乐博彩「杀」三倍赔付；第493章 以赌命做赌注；第1285章 隔空对赌
**何时用**：对手可以在『跟/弃』之间选择，我可以选择下注额 / 需要算对手该防守多宽、我该诈唬多少 / 赔率不对称（杀/胜/负三档赔付）

## 1. 形式化定义
底池 $P$，下注 $b$。

- 对手的最小防守频率：$\text{MDF}=\dfrac{P}{P+b}$（低于此值，我用任意两张牌诈唬都是 +EV）
- 我的诈唬上限：$\alpha=\dfrac{b}{P+b}$（超过即被「永远跟注」剥削）
- 均衡诈唬占所有下注的比例：$\dfrac{b}{P+2b}$，即价值:诈唬 $=(P+b):b$
- 纯诈唬 EV：$\text{EV}=f\cdot P-(1-f)\cdot b$，$f$ = 对手弃牌率；$f^\*=\text{MDF}$ 为无差异点
- 赔付倍数 $m$ 时把底池替换为 $mP$：$\text{MDF}_m=\dfrac{mP}{mP+b}$

**共同成本**：场地费/抽水 $t$ 直接从 EV 扣除；名义 +EV 与实际 +EV 经常符号相反。

## 2. 故事 → 模型 的映射表

| 故事要素（已确认的规则/情节） | 模型符号 | 建模说明 |
|---|---|---|
| 朔望月的下注/加注/跟注循环 | P 与 b | 每一轮加注都会改变 b，从而改变 MDF |
| 极乐博彩押「杀」额外多赔一倍 | 赔付倍数 m≈2–3 | 高赔率档把 MDF 抬到 6/7，对手必须防守 |
| 胜利要交一颗「道」的场地费 | 抽水 t | 小注赢利的玩家会被抽干 |
| 「识破即被骗」 | 对手读牌后的剥削 | 我的诈唬比例一旦超过 α 就会被无限跟注 |

## 3. 决策流程（照做即可）

- 1) 算底池赔率：对手要跟注 b 争 P+b，其最小防守频率 MDF = P/(P+b)。
- 2) 我的诈唬比例上限 α = b/(P+b)：超过这个比例，对手可以用『永远跟注』剥削我。
- 3) 反向：若对手防守频率 d < MDF，我用任意两张牌诈唬都是 +EV；若 d > MDF，我只用价值牌下注。
- 4) 混合：在诈唬与价值之间用随机化保持无差异（G5），并按牌面阻断（blocker）微调。
- 5) 赔率不对称时（如『杀』三倍赔付）：先把赔付折算成等效底池，再套公式。

## 4. 判定 checklist（任一不过 → 不要下注）

- [ ] 底池里有多少是对手已经投入的『死钱』（可被我白拿）？
- [ ] 我的下注额 b 是否大到让对手的 MDF 低到不可维持？
- [ ] 对手是否在情绪化跟注（d 偏高）/ 情绪化弃牌（d 偏低）？
- [ ] 我是否有『不用 showdown 就能赢』的合法动作（弃牌迫使/规则漏洞）？

## 5. 危险信号 / 反制 / 失败条件

**危险信号**：我连续下注且对手从不弃牌 -> 我的诈唬比例超了；对手在我下注后加注 -> 我的价值/诈唬比被读出来了

**反制**：
- 调整下注尺度改变 MDF 结构
- 用『杀』这类高赔率档位反向定价对手的恐惧
- 在被读牌时切换成纯价值模式

**失败条件（踩中任意一条=这套策略会送你死）**：
- 诈唬比例 > α -> 被无限跟注剥削
- 防守频率 < MDF -> 被无限诈唬剥削
- 忽略抽水/场地费（极乐博彩每胜要交一颗道）-> 名义 +EV 实际 -EV

## 6. 建模假设（不可外推的部分）

- P/b/m 是抽象单位；原文只给规则（加倍赔付、场地费），没给具体底池。
- 假设对手只有「跟/弃」两种反应；引入加注后需要博弈树（G6）。

## 7. 与其他模型的联动
G8 是 G5 的闭式特例（双方各两动作的扑克化简）；与 G4 联动时，抽水/场地费必须进机制审计。

## 8. 本仓库实测输出
`g8_bluff_jile.json`（P=2,b=1,m=3,f=0.45）：MDF=2/3、α=1/3、诈唬占比=1/4、价值:诈唬=3:1；对手弃牌率 0.45<MDF → 纯诈唬 EV=+0.35/次 → 判定「提高诈唬频率直到他把跟注率提到 2/3」。「杀」档把 MDF 抬到 6/7=0.857，等于把对手逼进必须防守的窄区间。
