## 1. 形式化定义
**机制** $\mathcal{M}=(M_1,M_2,x,p)$：报告空间 $M_i$，分配规则 $x\colon M\to[0,1]^2$，支付规则 $p\colon M\to\mathbb{R}^2$；
类型 $\theta_i$ 的效用 $u_i=\theta_i x_i-p_i$。

- **DSIC（占优策略激励相容）**：$\forall \theta_i,\ \forall m_{-i},\ u_i(\theta_i,(\theta_i,m_{-i}))\ \ge\ u_i(\theta_i,(m_i,m_{-i}))$
- **BIC**：把上式对 $m_{-i}$ 取期望（先验下说真话最优）
- **IR（参与约束）**：$\mathbb{E}_{m_{-i}}[u_i(\theta_i,(\theta_i,m_{-i}))]\ \ge\ 0$（保留效用）
- **预算平衡**：$\sum_i p_i\ \ge\ 0$（弱）／$=0$（强）
- **可行性**：$x_1+x_2\le 1$（不能「印资源」）——违反即为免费午餐
- **效率**：$\mathbb{E}\big[\sum_i \theta_i x_i\big]\ \le\ \max_i \theta_i$（单物品一阶最优）

**文本层审计（不可形式化部分）**：判定函数、平局规则、时限、解释权归属、隐藏规则权限、惩罚执行者的动机。

## 3. 决策流程（照做即可）

- 1) 抄全规则原文，逐条标注：定义了的 / 未定义的 / 可被谁解释的。
- 2) 检查激励相容（DSIC/BIC）：说真话是否是每个参与者的最优策略；若不是，规则实际在奖励说谎。
- 3) 检查参与约束（IR）：每个类型参与是否比不参与更好；若不好，被强制参与的人会破坏机制（摆烂/同归于尽）。
- 4) 检查预算平衡与铸币：是否存在『不付出就获得』的免费午餐（负支付、重复结算、可复制凭证）。
- 5) 检查可行性：分配概率之和是否 ≤1（是否在『印资源』）。
- 6) 输出漏洞清单：未定义项（判定函数/平局/时限/解释权）+ 套利项（免费动作/负成本动作）+ 强制项（不可拒绝的义务）。
- 7) 设计补丁：把关键判定函数写死、加平局规则、加时间戳、把解释权分散给多方。

## 4. 判定 checklist（任一不过 → 不要下注）

- [ ] 胜/负/平局的判定函数是否唯一确定？平局算谁赢？（第668章 平局算输）
- [ ] 时限、顺序、先手权是否定义？谁先动？
- [ ] 『最终解释权』在谁手里？他是否也是利益相关方？
- [ ] 规则是否允许某个玩家合法地使用规则外动作（生肖可隐藏规则权限差异）？
- [ ] 奖励是否可被同一人重复领取？凭证是否可伪造/转让？
- [ ] 惩罚是否可执行？执行者是否有动机执行？

## 5. 危险信号 / 反制 / 失败条件

**危险信号**：合同里嵌了自杀/自裁条款（飞升对赌合同）；规则用口头广播传达；关键判定词使用了可多解的形容词（如『有趣』『更重要』）

**反制**：
- 把口播规则变成书面并要求确认
- 要求写入平局与例外条款
- 把解释权拆成需要多方同意
- 故意触发一次边缘情况来测试裁判

**失败条件（踩中任意一条=这套策略会送你死）**：
- 不看规则全文就下注
- 假设对方会遵守对自己不利的条款
- 把『规则没写』当成『规则不允许』（通常是隐藏权限）

## 6. 建模假设（不可外推的部分）

- 把「自吹者拿到名额」编码成 x=1，把「赌注」编码成 p，是对合同的结构化抽象；原文没有数值。
- 工具默认参与者只有两类、报告空间两值；真实场景类型连续时需扩展（结论方向通常是「DSIC 更难满足」）。
- IR 用 0 作保留效用；若参与本身是强制的（拒令即抹杀），保留效用是 −∞，IR 检查会自动失败——这正是「被强制者会破坏机制」的数学表达。
