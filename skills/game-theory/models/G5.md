# G5　混合策略与纳什均衡（随机化）

**标准模型**：Mixed-Strategy Nash Equilibrium / Randomization
**脚本入口**：`python3 scripts/gt/qixia_gt.py mixed --file <json>`　（`--json` 输出机器可读结果）
**原书锚点**：终极游戏「朔望月」；极乐博彩下注分布；人猪「黑白棋」概率分配；第1082章 最终博弈
**何时用**：没有纯策略均衡，或纯策略会被对手针对 / 需要在多个动作之间随机化以保持不可预测 / 需要算对手的均衡频率来制定压注/诈唬比例

## 1. 形式化定义
混合策略 $\sigma_i\in\Delta(A_i)$，期望效用 $u_i(\sigma)=\sum_{a}\sigma_1(a_1)\sigma_2(a_2)u_i(a)$。
纳什均衡：$u_i(\sigma_i,\sigma_{-i})\ge u_i(\sigma_i',\sigma_{-i})$ 对所有 $\sigma_i'$。

**2×2 解析解**（行玩家选行 0 的概率 $p$、列玩家选列 0 的概率 $q$）：
$$q=\frac{u_1^{11}-u_1^{01}}{u_1^{00}-u_1^{01}-u_1^{10}+u_1^{11}},\qquad
p=\frac{u_2^{11}-u_2^{10}}{u_2^{00}-u_2^{10}-u_2^{01}+u_2^{11}}$$
（分母为 0 ⇒ 无内点混合均衡。）

**支撑枚举**（$n\times m$）：对每个支撑对 $(S_1,S_2)$，$|S_1|=|S_2|$，解「让对手在各纯动作间无差异」的线性方程组，
再检验所有未用动作不优于均衡收益。零和博弈的均衡值 = maximin 值（冯·诺依曼）。

## 2. 故事 → 模型 的映射表

| 故事要素（已确认的规则/情节） | 模型符号 | 建模说明 |
|---|---|---|
| 朔望月的「明牌/暗牌/公共牌」 | 信息结构（不完全信息） | 暗牌 = 私人信息，公共牌 = 共同观测 |

## 3. 决策流程（照做即可）

- 1) 写出收益矩阵，先找纯策略纳什均衡（有就用，别乱随机）。
- 2) 若无纯均衡：令对手在动作间无差异，解出各动作概率（2x2 有解析解；n×m 用支撑枚举）。
- 3) 用混合策略时，随机化必须是真随机（不可被观察出规律），否则对手会读牌。
- 4) 算对手偏离的收益差：若对手偏离的收益差很小，说明均衡脆弱，可用心理战/信息战放大。
- 5) 反过来：若发现自己在均衡中被压榨（EV<0），说明我不该玩这个游戏——改变规则或退出（G4/G6）。

## 4. 判定 checklist（任一不过 → 不要下注）

- [ ] 纯策略均衡是否存在？随机化是否只是在掩盖一个本来就该确定的决策？
- [ ] 我的随机化是否可被观测/统计出来（时间间隔、下注额规律）？
- [ ] 对手是否在『非均衡』地行动（可被剥削）？剥削需要样本量，我的样本够吗？
- [ ] 均衡只是防守线，不是盈利线：均衡 EV 是否为负？

## 5. 危险信号 / 反制 / 失败条件

**危险信号**：对手在长序列中表现出稳定的偏差（可利用）；游戏赔付结构（抽水/场地费）本身让 EV<0

**反制**：
- 对可剥削对手做最大化剥削（exploitative）调整
- 改变赔付结构/规则（G4）把负 EV 变正
- 加噪音：把随机化种子外置（骰子/第三方）

**失败条件（踩中任意一条=这套策略会送你死）**：
- 在有限样本上判断对手偏差 -> 过拟合
- 用固定周期随机化 -> 被读牌
- 把均衡当必胜法 -> 忽略抽水与方差

## 6. 建模假设（不可外推的部分）

- 把德州扑克化的朔望月压缩成 2×2（价值下注/诈唬 vs 跟注/弃牌）是教学简化；真实牌局的均衡需要按牌力分布求连续混合策略。
- 「价值下注被跟 = 多赢 1、对手弃 = 0」对应底池 P=2、下注 b=1 的设定，是建模假设。
