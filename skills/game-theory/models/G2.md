# G2　不完全信息与贝叶斯更新

**标准模型**：Incomplete Information / Bayesian Updating / Value of Information
**脚本入口**：`python3 scripts/gt/qixia_gt.py bayes --file <json>`　（`--json` 输出机器可读结果）
**原书锚点**：第644章 真假规则；第648章 超核运算；地羊「四情扇」隐藏规则；人蛇「是与非」
**何时用**：对手类型/规则版本/隐藏条款未知 / 可以用行动或提问换取信息 / 需要在信息不足时下注

## 1. 形式化定义
**贝叶斯更新**：状态 $\theta\in\Theta$，先验 $p(\theta)$，观测 $s$，

$$p(\theta\mid s)=\frac{p(s\mid\theta)p(\theta)}{\sum_{\theta'}p(s\mid\theta')p(\theta')},\qquad
\underbrace{\frac{p(\theta_1\mid s)}{p(\theta_2\mid s)}}_{\text{后验几率}}=\underbrace{\frac{p(\theta_1)}{p(\theta_2)}}_{\text{先验几率}}\times
\underbrace{\frac{p(s\mid\theta_1)}{p(s\mid\theta_2)}}_{\text{似然比 LR}}$$

LR≈1 的信号没有信息量；LR 极端（如 18:1）一次观测即可定案。

**信息价值**：
$$\text{EVPI}=\mathbb{E}_\theta\big[\max_a u(a,\theta)\big]-\max_a \mathbb{E}_\theta\big[u(a,\theta)\big]$$

EVPI 是「完美信息」的价值上限；任何侦查成本超过 EVPI 都是亏本买卖。

## 2. 故事 → 模型 的映射表

| 故事要素（已确认的规则/情节） | 模型符号 | 建模说明 |
|---|---|---|
| 「地羊到底是裁判还是参与者」 | 状态 θ1 / θ2 | 四情扇的隐藏规则：地羊在本局属参与者、可花道买扇 |
| 看见地羊花道买扇 | 观测 s（LR≈18:1） | 只有参与者才需要/才能买扇 |
| 「先花道买扇试一试」这个动作 | 主动取证动作 | 花小成本把 LR 极端化，比盲押便宜 |
| 隐藏规则未公布 | 先验不确定 | 未公布 ≠ 不存在；LR 极端的观测往往只在隐藏规则下出现 |

## 3. 决策流程（照做即可）

- 1) 列出状态空间（对手类型、规则版本、底牌集合），给出先验。
- 2) 列出可观测信号（他的动作、停顿、用词、下注额、你被允许问的问题）。
- 3) 用贝叶斯公式更新：P(θ|s) ∝ P(s|θ)P(θ)。
- 4) 用更新后的后验重算每个动作的期望值，选择 EV 最大者。
- 5) 算信息价值：EVPI = EV(完美信息) - EV(当前)，若 EVPI < 获取信息的成本则不要问。
- 6) 反向使用：设计一个只有某类型才会做出的动作，把对方的私有信息『逼』成公开信号（见 G3）。

## 4. 判定 checklist（任一不过 → 不要下注）

- [ ] 先验是从哪来的？如果是别人告诉我的，它本身可能是假信号。
- [ ] 这个信号是否被对手操纵（他可以故意发假信号）？
- [ ] 我是否把『他没反应』当成了证据？无信号也是信号（沉默成本=他不在乎）。
- [ ] 后验是否已经过时（规则被改过/信息被洗过）？

## 5. 危险信号 / 反制 / 失败条件

**危险信号**：对手给出『恰好能让我安心』的信息；信息只在口头层面存在，无法交叉验证

**反制**：
- 交叉验证：用两个独立信源验证同一命题
- 构造只能由真类型支付的昂贵信号（G3）
- 故意泄露假信息测试对手反应（信息投毒）

**失败条件（踩中任意一条=这套策略会送你死）**：
- 把先验当事实 -> 全盘押错
- 忽略对手的信号操纵能力 -> 被反向利用
- 信息价值低于成本仍去探索 -> 浪费唯一机会

## 6. 建模假设（不可外推的部分）

- 先验 0.5 与似然（0.05/0.9、0.2/0.8）是建模假设，用来演示「一次观测就能翻转判断」的力度，不是原文数据。
- 假设对手不会为了骗我而故意做出「只有参与者才会做」的昂贵动作——若他会，需升级到 G3（信号可被伪造）。

## 7. 与其他模型的联动
G2 提供后验 → G3 判断信号是否被操纵 → G9 把后验转成下注比例。

## 8. 本仓库实测输出
案例 `cases/gt/g2_bayes_siqingshan.json`：先验 0.5/0.5，观测「地羊花道买扇」LR=1/18 → 后验 V1=1/19、V2=18/19；再叠加「地羊扇面被赢走过」后进一步集中。EVPI 输出显示：再花大力气取证的价值已很低，应转执行。
