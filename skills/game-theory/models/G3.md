# G3　信号博弈与甄别（分离/混同均衡）

**标准模型**：Signaling Game (Spence) / Screening / Separating vs Pooling
**脚本入口**：`python3 scripts/gt/qixia_gt.py signaling --file <json>`　（`--json` 输出机器可读结果）
**原书锚点**：生肖飞升对赌合同（嵌入式自杀条款）；第654章 识破即被骗；第1063章 布局开始；第1318章 三方对赌
**何时用**：我比对手更清楚自己的类型（强/弱、真/假） / 需要一个『只有某类型才付得起』的动作来证明自己 / 对手想通过合同菜单让我暴露类型

## 1. 形式化定义
**信号博弈** $(S,(M),(A))$：发送方类型 $\theta\in\{\theta_H,\theta_L\}$，先验 $p$；发送信号 $m$；接收方观测 $m$ 后选动作 $a$。

完美贝叶斯均衡（PBE）由「发送策略 + 接收策略 + 信念 $\mu(\theta\mid m)$」组成，需满足：
1. 接收方序贯理性：$a^\*(m)\in\arg\max_a \sum_\theta \mu(\theta\mid m)u_R(m,a,\theta)$；
2. 发送方序贯理性：$m^\*(\theta)\in\arg\max_m u_S(\theta,m,a^\*(m))$；
3. 在轨信念由贝叶斯法则给出；离轨信念任意（这就是混同/分离多解的来源）。

**单交叉条件**（信号有信息量的必要条件）：
$$\frac{\partial}{\partial\theta}\Big[u_S(\theta,m_H)-u_S(\theta,m_L)\Big]>0$$
即「强类型发强信号的机会成本更低」。成本与类型无关 ⇒ 信号无信息量 ⇒ 只可能混同。

**甄别（对偶视角）**：接收方主动提供菜单让发送方自选，等价于 G11。

## 3. 决策流程（照做即可）

- 1) 定义类型 θ（强/弱、真货/假货、回响者/普通人）与先验。
- 2) 定义信号 m 与成本 c(m,θ)：**单交叉条件**——强类型发同一信号的边际成本必须更低，否则信号无信息量。
- 3) 求分离均衡：强类型发昂贵信号、弱类型不发；核对弱类型的模仿激励是否被成本差挡住（IC）。
- 4) 求混同均衡：两类发同一信号，接收方只能用先验行动；核对是否存在偏离激励。
- 5) 若我是接收方（被信号轰炸方）：设计合同菜单让不同类型自选（见 screening / G4）。
- 6) 若我是发送方：优先选『烧掉自己退路』的信号（自杀条款、公开赌命），因为弱者无法模仿。

## 4. 判定 checklist（任一不过 → 不要下注）

- [ ] 信号成本是否真的按类型不同（单交叉）？若成本相同，信号只是噪声。
- [ ] 对手是否可能『装强』装到底（pooling）？装到底的成本他付得起吗？
- [ ] 我发出的信号是否可被伪造/租借（借来的回响、借来的底牌）？
- [ ] 分离均衡是否唯一？若存在混同均衡，我的信号可能被无视。

## 5. 危险信号 / 反制 / 失败条件

**危险信号**：对手要求的信号成本对所有类型相同；对手给出『不用证明我也信你』的承诺

**反制**：
- 引入可验证的第三方凭证
- 设计阶梯式信号（小信号->大信号），逐步加价筛选
- 把对手的混同策略变成对我不利的共同知识（公开点名要求自证）

**失败条件（踩中任意一条=这套策略会送你死）**：
- 用了无成本信号 -> 完全无信息量，被当作空话
- 只算自己发信号的成本，没算对手模仿的成本 -> 被冒充
- 忽略混同均衡 -> 自信误判

## 6. 建模假设（不可外推的部分）

- 收益数值（10/4/2/-8 等）是建模假设；原文只给规则文本，没有数值。
- 「弱类型签了会死」被折算成 −8 的效用，这是把处决等价成负效用，属于简化。
- 模型只覆盖两类型两信号两动作；引入「连续类型」会让分离条件变成单调性条件，结论方向不变。
