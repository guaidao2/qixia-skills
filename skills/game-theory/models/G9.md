# G9　概率分配与随机化设计

**标准模型**：Probability Design / Mixing over Allocations
**脚本入口**：`python3 scripts/gt/qixia_gt.py prob --file <json>`　（`--json` 输出机器可读结果）
**原书锚点**：人猪「黑白棋」（50黑50白分两碗）；人猪赌命版（一真一假只能问一次）；极乐彩券（红绿白十二字）
**何时用**：可以让对手在『随机结果』上做选择，而我能先设计分布 / 需要在信息不对称下把胜率最大化 / 需要在一次性事件中把概率拉到极限

## 1. 形式化定义
**概率分配设计**：把 $B$ 颗黑子、$W$ 颗白子分到两个碗（$b_1,w_1$）+（$B-b_1,W-w_1$），随机选碗后随机摸一颗：

$$\Pr(\text{黑})=\frac12\cdot\frac{b_1}{b_1+w_1}+\frac12\cdot\frac{B-b_1}{B-b_1+W-w_1}$$

在「两碗均非空」约束下求最大值：解恒为**极端集中**（$b_1=1,w_1=0$），
$\Pr=\frac12+\frac{B-1}{2(B+W-1)}$；对 $B=W=50$ 得 $\frac12+\frac{49}{198}=\frac{74}{99}\approx0.7475$。
平均分配只得 $\frac12$。

**线性约束的对照**：若规则要求「每碗恰好 50 颗」，则 $\Pr=\frac12\cdot\frac{b_1}{50}+\frac12\cdot\frac{50-b_1}{50}=\frac12$ 恒成立
——同一条规则的两种读法，胜率差 25 个百分点。

**元问题（消除说谎）**：问「如果我问你『$P$』，你会回答『是』吗？」→ 真话者与说谎者的回答都等价于 $P$ 的真值，
即 $\Pr(\text{得到真值})=1$，把「真假不确定性」压缩为 0。

## 3. 决策流程（照做即可）

- 1) 写出胜率表达式（对分配变量的函数），不要凭直觉分配。
- 2) 找极值：常见最优是『把极少数资源集中到一个极小概率但必胜的分支』（黑白棋：1黑 vs 49黑50白）。
- 3) 验证对手是否能通过选择规则剥削（让他选择碗 vs 随机选碗，结果不同）。
- 4) 若对手能问一次问题且一真一假：用元问题把『真/假』归一化（metaq 子命令），把不确定性降为 0。
- 5) 把结论写成可执行动作：分配比例、问法、下注额。

## 4. 判定 checklist（任一不过 → 不要下注）

- [ ] 对手的选择机制是否真的随机（谁摇匀、谁选碗）？
- [ ] 我设计的分布是否被对手知道？知道后他能否反制？
- [ ] 是否存在『必胜但概率极低』的分支被浪费？
- [ ] 一次性事件中，我是否在用大数定律的直觉处理单次抽样？

## 5. 危险信号 / 反制 / 失败条件

**危险信号**：『公平分配』的直觉；对手主动提议规则（他可能已经算过极值）

**反制**：
- 把分布设计权抓在自己手里（我来分、他来选）
- 用元问题消除真假不确定性
- 若无法设计分布，改为设计赔付（G8）

**失败条件（踩中任意一条=这套策略会送你死）**：
- 平均分配 -> 胜率仅约 50%
- 忽略对手自选碗的权利 -> 最优解失效
- 把随机当确定性 -> 单次失手

## 6. 建模假设（不可外推的部分）

- 假设「随机选碗、随机摸一颗」由裁判执行且均匀分布；若由对手选碗，最优分配失效（他会选白多的那碗）。
- 假设一把抓的时候不透明（摇匀），否则可通过触感作弊。

## 7. 与其他模型的联动
