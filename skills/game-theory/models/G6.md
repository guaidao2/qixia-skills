# G6　逆向归纳与承诺可信度（子博弈完美）

**标准模型**：Backward Induction / SPNE / Credible Commitment
**脚本入口**：`python3 scripts/gt/qixia_gt.py backward --file <json>`　（`--json` 输出机器可读结果）
**原书锚点**：第120章 生肖飞升对赌合同；第685章 很长的计划；第1128章 我有一计；仓颉棋「拒令即抹杀」；青龙游戏（四天杀八个地级生肖）
**何时用**：行动有先后顺序，需要判断对手最后一步会不会真的执行 / 对手在威胁我，需要判断威胁是否可信 / 需要设计一个『即使对我短期不利也必须执行』的承诺

## 1. 形式化定义
扩展型博弈 $\Gamma=(N,H,P,u)$：$H$ 为历史集合，$P(h)$ 为行动者，$u_i$ 定义在终局 $Z$ 上。

**逆向归纳**：对每个非终局节点 $h$，$a^\*(h)\in\arg\max_{a} u_{P(h)}(h a)$，从叶子向上递推。
有限完全信息博弈的 SPNE 由逆向归纳唯一给出（若每步最优唯一）。

**不可信威胁**：若某玩家宣称会在节点 $h$ 选 $a$，但 $a\notin\arg\max$，则该威胁在 SPNE 下不会被执行——
它是 cheap threat，除非玩家能**改变自己的收益**（自缚承诺）：
$$\text{可信} \iff u_i(h a)\ \ge\ u_i(h a')\ \text{在承诺生效后成立}$$

承诺的三类实现：① 把执行权交给利益一致的第三方；② 让不执行的成本更高（抵押、人质、公开立誓）；③ 自动化装置（机关/合同）。

## 2. 故事 → 模型 的映射表

| 故事要素（已确认的规则/情节） | 模型符号 | 建模说明 |
|---|---|---|
| 仓颉棋「拒令即溃逃之将，当场抹杀」 | 由第三方（地龙）执行的惩罚 | 执行者无成本且有动机 → 威胁可信 |
| 若改成「主帅自己动手处决」 | self-execution | 主帅自损战力 → 逆向归纳判定威胁不可信 |

## 3. 决策流程（照做即可）

- 1) 画出博弈树：谁先动、谁能观测、终局收益是多少。
- 2) 从叶子往回算：每个节点上行动者会选收益最大的动作（逆向归纳）。
- 3) 得到 SPNE 路径；任何与 SPNE 不一致的『威胁』都是不可信威胁（cheap threat）。
- 4) 若要威胁可信：必须有自缚机制——把执行成本外部化/让不执行的成本更高（公开立誓、交出人质、设自动装置）。
- 5) 先手价值 = 我先动的 SPNE 收益 - 后动的 SPNE 收益；若先手价值为负，让对方先动。
- 6) 若树太深，只算关键的最后三步（终局结算层），因为所有前序策略都要服从终局结算。

## 4. 判定 checklist（任一不过 → 不要下注）

- [ ] 终局是谁结算的？他有动机按规则结算吗？
- [ ] 对手的威胁在最后一步对他自己有利吗？不利=不可信。
- [ ] 我的承诺是否有自动执行装置（合同/机关/第三方）？
- [ ] 我是否假设对手会在对自己不利时仍然履约？

## 5. 危险信号 / 反制 / 失败条件

**危险信号**：对手的威胁需要他付出巨大代价才能执行；合同约定由对手自己执行对我的惩罚（他有动机不执行/篡改）

**反制**：
- 把承诺写进不可撤销的机制（G4）
- 让第三方持有执行权且其利益与履约一致
- 制造『不执行就立刻损失更大』的局面

**失败条件（踩中任意一条=这套策略会送你死）**：
- 把不可信威胁当真 -> 过度让步
- 把可信承诺当虚张声势 -> 被处决
- 忽略终局结算者的利益 -> 赢了也被判输

## 6. 建模假设（不可外推的部分）

- 博弈树是本仓库搭建的结构化抽象：节点/动作/收益都是建模假设，只有「拒令即抹杀」这条规则来自原文。
- 假设参与者追求自身存活收益最大化；若对方有「执念」（如为妻子/为同伴牺牲），收益函数需要重设，逆向归纳结果会翻转——这本身是可利用的信息。

## 7. 与其他模型的联动
G6 依赖 G4 给出的规则与执行者；G6 的输出（可信/不可信）决定 G1 的惩罚能否支撑合作、G7 的承诺是否值得投入。
