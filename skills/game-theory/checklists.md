# 博弈论判定 checklist（全 12 模型）

> 由 `python3 scripts/gt/qixia_gt.py checklist --format md` 生成的内容与本节一致。
> 用法：进入任何一个局，按你识别出的模型逐条打勾；有任意一条打不了勾，就去补信息，不要下注。

## G1 囚徒困境与重复博弈 (Prisoner's Dilemma / Repeated Game (Folk Theorem))
- 脚本入口: `python3 qixia_gt.py pd --file <json>`
- 原书锚点: 第278章 囚徒困境；第567章 骗亦是信；地狗「送信人」奸细阵营；极乐博彩「胜/负/杀」对赌
- 何时用: 存在「合作对双方都好，但单方背叛更划算」的收益结构 / 对手是理性且只结算一次 / 或会长期重复相遇 / 需要判断要不要先合作、要不要惩罚、惩罚多久
- 必需参数: 2x2 收益矩阵 (T,R,P,S 或完整矩阵)；重复次数或贴现因子 δ；对手类型先验
- 决策流程:
    1) 把局面写成 2x2：双方各有 C(合作/守信) 与 D(背叛/夺道) 两个动作。
    2) 判 T>R>P>S 是否成立，且 2R>T+S —— 成立才是真囚徒困境。
    3) 若一次性：唯一纳什均衡是 (D,D)，任何「我们合作吧」的口头承诺都是廉价的。
    4) 若重复：算临界贴现因子 δ* = (T-R)/(T-P)；δ≥δ* 时触发策略可支撑合作。
    5) 选触发策略：针锋相对(TFT) / 冷酷触发(Grim) / 以牙还牙+宽恕；对手背叛一次的反制速度要快于其收益回收期。
    6) 若对手不知道 δ（信息不完全），用「可观测的惩罚承诺」把 δ 变成共同知识（公开处刑、公开撕票、公开立誓）。
- 判定 checklist（任一不过就别下注）:
    [ ] 是否确认过 2R>T+S？很多『囚徒困境』其实是猎鹿/胆小鬼博弈，策略完全相反。
    [ ] 对手的 T（背叛收益）是否被我低估？在他眼里背叛可能是零成本。
    [ ] 这场博弈是单次还是重复？对方是否认为『没有下一次』（末世/必死局常被判为单次）。
    [ ] 我的惩罚承诺是否可被观测？不可观测的惩罚 = 不存在。
    [ ] 合作是否有『可被单方摧毁的抵押品』（人质/共同资产/把柄）？
- 危险信号: 对手主动提出合作且拒绝立下可执行抵押；对手反复强调『这是最后一次』；规则允许杀人夺道（背叛收益≈无限）
- 反制: 制造可观测的重复关系（把一次性博弈改写成重复博弈）；先手自缚：公开销毁背叛选项（销毁钥匙/交出人质）；提高背叛成本：让第三方见证并承担惩罚义务
- 失败条件: 误把胆小鬼/猎鹿当囚徒困境 -> 该强硬时合作，被杀；单次博弈中先合作 -> 被一次性收割；惩罚承诺不可观测 -> 对手理性选择背叛

## G2 不完全信息与贝叶斯更新 (Incomplete Information / Bayesian Updating / Value of Information)
- 脚本入口: `python3 qixia_gt.py bayes --file <json>`
- 原书锚点: 第644章 真假规则；第648章 超核运算；地羊「四情扇」隐藏规则；人蛇「是与非」
- 何时用: 对手类型/规则版本/隐藏条款未知 / 可以用行动或提问换取信息 / 需要在信息不足时下注
- 必需参数: 先验概率；每种信号在各类型下的似然；可选动作与其收益
- 决策流程:
    1) 列出状态空间（对手类型、规则版本、底牌集合），给出先验。
    2) 列出可观测信号（他的动作、停顿、用词、下注额、你被允许问的问题）。
    3) 用贝叶斯公式更新：P(θ|s) ∝ P(s|θ)P(θ)。
    4) 用更新后的后验重算每个动作的期望值，选择 EV 最大者。
    5) 算信息价值：EVPI = EV(完美信息) - EV(当前)，若 EVPI < 获取信息的成本则不要问。
    6) 反向使用：设计一个只有某类型才会做出的动作，把对方的私有信息『逼』成公开信号（见 G3）。
- 判定 checklist（任一不过就别下注）:
    [ ] 先验是从哪来的？如果是别人告诉我的，它本身可能是假信号。
    [ ] 这个信号是否被对手操纵（他可以故意发假信号）？
    [ ] 我是否把『他没反应』当成了证据？无信号也是信号（沉默成本=他不在乎）。
    [ ] 后验是否已经过时（规则被改过/信息被洗过）？
- 危险信号: 对手给出『恰好能让我安心』的信息；信息只在口头层面存在，无法交叉验证
- 反制: 交叉验证：用两个独立信源验证同一命题；构造只能由真类型支付的昂贵信号（G3）；故意泄露假信息测试对手反应（信息投毒）
- 失败条件: 把先验当事实 -> 全盘押错；忽略对手的信号操纵能力 -> 被反向利用；信息价值低于成本仍去探索 -> 浪费唯一机会

## G3 信号博弈与甄别（分离/混同均衡） (Signaling Game (Spence) / Screening / Separating vs Pooling)
- 脚本入口: `python3 qixia_gt.py signaling --file <json>`
- 原书锚点: 生肖飞升对赌合同（嵌入式自杀条款）；第654章 识破即被骗；第1063章 布局开始；第1318章 三方对赌
- 何时用: 我比对手更清楚自己的类型（强/弱、真/假） / 需要一个『只有某类型才付得起』的动作来证明自己 / 对手想通过合同菜单让我暴露类型
- 必需参数: 类型集合与先验；信号集合及其按类型的成本；接收方动作与收益
- 决策流程:
    1) 定义类型 θ（强/弱、真货/假货、回响者/普通人）与先验。
    2) 定义信号 m 与成本 c(m,θ)：**单交叉条件**——强类型发同一信号的边际成本必须更低，否则信号无信息量。
    3) 求分离均衡：强类型发昂贵信号、弱类型不发；核对弱类型的模仿激励是否被成本差挡住（IC）。
    4) 求混同均衡：两类发同一信号，接收方只能用先验行动；核对是否存在偏离激励。
    5) 若我是接收方（被信号轰炸方）：设计合同菜单让不同类型自选（见 screening / G4）。
    6) 若我是发送方：优先选『烧掉自己退路』的信号（自杀条款、公开赌命），因为弱者无法模仿。
- 判定 checklist（任一不过就别下注）:
    [ ] 信号成本是否真的按类型不同（单交叉）？若成本相同，信号只是噪声。
    [ ] 对手是否可能『装强』装到底（pooling）？装到底的成本他付得起吗？
    [ ] 我发出的信号是否可被伪造/租借（借来的回响、借来的底牌）？
    [ ] 分离均衡是否唯一？若存在混同均衡，我的信号可能被无视。
- 危险信号: 对手要求的信号成本对所有类型相同；对手给出『不用证明我也信你』的承诺
- 反制: 引入可验证的第三方凭证；设计阶梯式信号（小信号->大信号），逐步加价筛选；把对手的混同策略变成对我不利的共同知识（公开点名要求自证）
- 失败条件: 用了无成本信号 -> 完全无信息量，被当作空话；只算自己发信号的成本，没算对手模仿的成本 -> 被冒充；忽略混同均衡 -> 自信误判

## G4 机制设计与规则审计（激励相容/参与约束/漏洞） (Mechanism Design (BIC/DSIC, IR, budget balance) & Rule Audit)
- 脚本入口: `python3 qixia_gt.py mechanism --file <json>`
- 原书锚点: 第438章 隐藏的规则；第460章 未曾提及的规则；第463章 规则更改；第831章 规则盲点；生肖守则九条 / 赌命规则八条
- 何时用: 规则是我（或对手）写的，需要让人『自愿』按我设计的方式行动 / 需要检查规则里是否有可套利/可钻的空子 / 需要判断对方设计的规则在鼓励什么行为
- 必需参数: 参与者类型分布；分配规则（谁得到什么）；支付规则（谁付什么）
- 决策流程:
    1) 抄全规则原文，逐条标注：定义了的 / 未定义的 / 可被谁解释的。
    2) 检查激励相容（DSIC/BIC）：说真话是否是每个参与者的最优策略；若不是，规则实际在奖励说谎。
    3) 检查参与约束（IR）：每个类型参与是否比不参与更好；若不好，被强制参与的人会破坏机制（摆烂/同归于尽）。
    4) 检查预算平衡与铸币：是否存在『不付出就获得』的免费午餐（负支付、重复结算、可复制凭证）。
    5) 检查可行性：分配概率之和是否 ≤1（是否在『印资源』）。
    6) 输出漏洞清单：未定义项（判定函数/平局/时限/解释权）+ 套利项（免费动作/负成本动作）+ 强制项（不可拒绝的义务）。
    7) 设计补丁：把关键判定函数写死、加平局规则、加时间戳、把解释权分散给多方。
- 判定 checklist（任一不过就别下注）:
    [ ] 胜/负/平局的判定函数是否唯一确定？平局算谁赢？（第668章 平局算输）
    [ ] 时限、顺序、先手权是否定义？谁先动？
    [ ] 『最终解释权』在谁手里？他是否也是利益相关方？
    [ ] 规则是否允许某个玩家合法地使用规则外动作（生肖可隐藏规则权限差异）？
    [ ] 奖励是否可被同一人重复领取？凭证是否可伪造/转让？
    [ ] 惩罚是否可执行？执行者是否有动机执行？
- 危险信号: 合同里嵌了自杀/自裁条款（飞升对赌合同）；规则用口头广播传达；关键判定词使用了可多解的形容词（如『有趣』『更重要』）
- 反制: 把口播规则变成书面并要求确认；要求写入平局与例外条款；把解释权拆成需要多方同意；故意触发一次边缘情况来测试裁判
- 失败条件: 不看规则全文就下注；假设对方会遵守对自己不利的条款；把『规则没写』当成『规则不允许』（通常是隐藏权限）

## G5 混合策略与纳什均衡（随机化） (Mixed-Strategy Nash Equilibrium / Randomization)
- 脚本入口: `python3 qixia_gt.py mixed --file <json>`
- 原书锚点: 终极游戏「朔望月」；极乐博彩下注分布；人猪「黑白棋」概率分配；第1082章 最终博弈
- 何时用: 没有纯策略均衡，或纯策略会被对手针对 / 需要在多个动作之间随机化以保持不可预测 / 需要算对手的均衡频率来制定压注/诈唬比例
- 必需参数: 收益矩阵；可选动作集合
- 决策流程:
    1) 写出收益矩阵，先找纯策略纳什均衡（有就用，别乱随机）。
    2) 若无纯均衡：令对手在动作间无差异，解出各动作概率（2x2 有解析解；n×m 用支撑枚举）。
    3) 用混合策略时，随机化必须是真随机（不可被观察出规律），否则对手会读牌。
    4) 算对手偏离的收益差：若对手偏离的收益差很小，说明均衡脆弱，可用心理战/信息战放大。
    5) 反过来：若发现自己在均衡中被压榨（EV<0），说明我不该玩这个游戏——改变规则或退出（G4/G6）。
- 判定 checklist（任一不过就别下注）:
    [ ] 纯策略均衡是否存在？随机化是否只是在掩盖一个本来就该确定的决策？
    [ ] 我的随机化是否可被观测/统计出来（时间间隔、下注额规律）？
    [ ] 对手是否在『非均衡』地行动（可被剥削）？剥削需要样本量，我的样本够吗？
    [ ] 均衡只是防守线，不是盈利线：均衡 EV 是否为负？
- 危险信号: 对手在长序列中表现出稳定的偏差（可利用）；游戏赔付结构（抽水/场地费）本身让 EV<0
- 反制: 对可剥削对手做最大化剥削（exploitative）调整；改变赔付结构/规则（G4）把负 EV 变正；加噪音：把随机化种子外置（骰子/第三方）
- 失败条件: 在有限样本上判断对手偏差 -> 过拟合；用固定周期随机化 -> 被读牌；把均衡当必胜法 -> 忽略抽水与方差

## G6 逆向归纳与承诺可信度（子博弈完美） (Backward Induction / SPNE / Credible Commitment)
- 脚本入口: `python3 qixia_gt.py backward --file <json>`
- 原书锚点: 第120章 生肖飞升对赌合同；第685章 很长的计划；第1128章 我有一计；仓颉棋「拒令即抹杀」；青龙游戏（四天杀八个地级生肖）
- 何时用: 行动有先后顺序，需要判断对手最后一步会不会真的执行 / 对手在威胁我，需要判断威胁是否可信 / 需要设计一个『即使对我短期不利也必须执行』的承诺
- 必需参数: 博弈树（节点、行动、终局收益）；各方宣告的威胁/承诺
- 决策流程:
    1) 画出博弈树：谁先动、谁能观测、终局收益是多少。
    2) 从叶子往回算：每个节点上行动者会选收益最大的动作（逆向归纳）。
    3) 得到 SPNE 路径；任何与 SPNE 不一致的『威胁』都是不可信威胁（cheap threat）。
    4) 若要威胁可信：必须有自缚机制——把执行成本外部化/让不执行的成本更高（公开立誓、交出人质、设自动装置）。
    5) 先手价值 = 我先动的 SPNE 收益 - 后动的 SPNE 收益；若先手价值为负，让对方先动。
    6) 若树太深，只算关键的最后三步（终局结算层），因为所有前序策略都要服从终局结算。
- 判定 checklist（任一不过就别下注）:
    [ ] 终局是谁结算的？他有动机按规则结算吗？
    [ ] 对手的威胁在最后一步对他自己有利吗？不利=不可信。
    [ ] 我的承诺是否有自动执行装置（合同/机关/第三方）？
    [ ] 我是否假设对手会在对自己不利时仍然履约？
- 危险信号: 对手的威胁需要他付出巨大代价才能执行；合同约定由对手自己执行对我的惩罚（他有动机不执行/篡改）
- 反制: 把承诺写进不可撤销的机制（G4）；让第三方持有执行权且其利益与履约一致；制造『不执行就立刻损失更大』的局面
- 失败条件: 把不可信威胁当真 -> 过度让步；把可信承诺当虚张声势 -> 被处决；忽略终局结算者的利益 -> 赢了也被判输

## G7 沉没成本与承诺升级（escalation） (Sunk Cost Fallacy / Escalation of Commitment / Burning Bridges)
- 脚本入口: `python3 qixia_gt.py sunk --file <json>`
- 原书锚点: 第250章 沉没成本；第617章 失算；十年前的「天秤游戏」；七年生肖之路；第886章 无法赌命
- 何时用: 已经投入巨大成本（时间/道/队友/记忆），继续 or 放弃 / 对手已投入巨大成本，可被诱导向继续加注 / 需要把『已投入』转化为可信承诺
- 必需参数: 已沉没成本 S；继续的增量成本 c；胜率 p 与胜利收益 V；放弃的保留收益 q
- 决策流程:
    1) 先把 S 从决策里划掉：它无论如何都收不回来，**不进入边际决策**。
    2) 只算增量：EV(继续) = p·V - c；与 q 比较。
    3) 算临界胜率 p* = (c+q)/V：低于 p* 就该立刻止损，无论此前投入多少。
    4) 反过来利用对手的沉没成本：让对手先投入（门票/抵押/公开承诺），再改变规则或提高价码，他会因为不甘心而继续加注。
    5) 若 S 可以转化为承诺（烧船/毁钥匙/公开立誓），则 S 不是浪费，而是买了『不可反悔』的可信度（G6）。
- 判定 checklist（任一不过就别下注）:
    [ ] 我继续的理由里，有多少是『为了不浪费已经投入的』？这部分必须剔除。
    [ ] 若今天是我第一次面对这个局面（S=0），我会投入吗？
    [ ] 对手是否在利用我的沉没成本加价？
    [ ] 止损的信号是否已经出现但我拒绝承认（第617章 失算）？
- 危险信号: 『已经走到这一步了』；『再撑一次就能翻盘』；加注额度越来越大而胜率没变
- 反制: 预先设定硬止损线并公开（外部约束）；把决策权交给未投入的第三方；要求对手先亮出他的沉没成本（谁更不敢退）
- 失败条件: 为了面子/执念继续加注 -> 归零；对所有人使用同一套沉没成本诱导 -> 遇到真能止损的人被反杀；把可回收资产当沉没成本销毁 -> 失去退出选项

## G8 诈唬频率与底池赔率（阈值/混合） (Bluffing Frequency, Pot Odds, MDF & Alpha)
- 脚本入口: `python3 qixia_gt.py bluff --file <json>`
- 原书锚点: 朔望月（德州扑克化）；极乐博彩「杀」三倍赔付；第493章 以赌命做赌注；第1285章 隔空对赌
- 何时用: 对手可以在『跟/弃』之间选择，我可以选择下注额 / 需要算对手该防守多宽、我该诈唬多少 / 赔率不对称（杀/胜/负三档赔付）
- 必需参数: 底池 P；下注额 b；我的手牌强度的估计分布；对手防守频率
- 决策流程:
    1) 算底池赔率：对手要跟注 b 争 P+b，其最小防守频率 MDF = P/(P+b)。
    2) 我的诈唬比例上限 α = b/(P+b)：超过这个比例，对手可以用『永远跟注』剥削我。
    3) 反向：若对手防守频率 d < MDF，我用任意两张牌诈唬都是 +EV；若 d > MDF，我只用价值牌下注。
    4) 混合：在诈唬与价值之间用随机化保持无差异（G5），并按牌面阻断（blocker）微调。
    5) 赔率不对称时（如『杀』三倍赔付）：先把赔付折算成等效底池，再套公式。
- 判定 checklist（任一不过就别下注）:
    [ ] 底池里有多少是对手已经投入的『死钱』（可被我白拿）？
    [ ] 我的下注额 b 是否大到让对手的 MDF 低到不可维持？
    [ ] 对手是否在情绪化跟注（d 偏高）/ 情绪化弃牌（d 偏低）？
    [ ] 我是否有『不用 showdown 就能赢』的合法动作（弃牌迫使/规则漏洞）？
- 危险信号: 我连续下注且对手从不弃牌 -> 我的诈唬比例超了；对手在我下注后加注 -> 我的价值/诈唬比被读出来了
- 反制: 调整下注尺度改变 MDF 结构；用『杀』这类高赔率档位反向定价对手的恐惧；在被读牌时切换成纯价值模式
- 失败条件: 诈唬比例 > α -> 被无限跟注剥削；防守频率 < MDF -> 被无限诈唬剥削；忽略抽水/场地费（极乐博彩每胜要交一颗道）-> 名义 +EV 实际 -EV

## G9 概率分配与随机化设计 (Probability Design / Mixing over Allocations)
- 脚本入口: `python3 qixia_gt.py prob --file <json>`
- 原书锚点: 人猪「黑白棋」（50黑50白分两碗）；人猪赌命版（一真一假只能问一次）；极乐彩券（红绿白十二字）
- 何时用: 可以让对手在『随机结果』上做选择，而我能先设计分布 / 需要在信息不对称下把胜率最大化 / 需要在一次性事件中把概率拉到极限
- 必需参数: 黑白子数量或等价的可分配资源；对手的选择方式（随机/自选/被规定）
- 决策流程:
    1) 写出胜率表达式（对分配变量的函数），不要凭直觉分配。
    2) 找极值：常见最优是『把极少数资源集中到一个极小概率但必胜的分支』（黑白棋：1黑 vs 49黑50白）。
    3) 验证对手是否能通过选择规则剥削（让他选择碗 vs 随机选碗，结果不同）。
    4) 若对手能问一次问题且一真一假：用元问题把『真/假』归一化（metaq 子命令），把不确定性降为 0。
    5) 把结论写成可执行动作：分配比例、问法、下注额。
- 判定 checklist（任一不过就别下注）:
    [ ] 对手的选择机制是否真的随机（谁摇匀、谁选碗）？
    [ ] 我设计的分布是否被对手知道？知道后他能否反制？
    [ ] 是否存在『必胜但概率极低』的分支被浪费？
    [ ] 一次性事件中，我是否在用大数定律的直觉处理单次抽样？
- 危险信号: 『公平分配』的直觉；对手主动提议规则（他可能已经算过极值）
- 反制: 把分布设计权抓在自己手里（我来分、他来选）；用元问题消除真假不确定性；若无法设计分布，改为设计赔付（G8）
- 失败条件: 平均分配 -> 胜率仅约 50%；忽略对手自选碗的权利 -> 最优解失效；把随机当确定性 -> 单次失手

## G10 共同知识与协调不可能（两军问题） (Common Knowledge / Coordination Impossibility (Two Generals))
- 脚本入口: `python3 qixia_gt.py common --file <json>`
- 原书锚点: 人蛇面试「两军问题」；第460章 未曾提及的规则；十人以上协同类游戏（不插队/送信人）
- 何时用: 需要多方同时行动才能成功 / 通信不可靠或需多轮确认 / 有人可能叛变/理解偏差
- 必需参数: 单条消息可靠性 p；确认轮数 n；协同失败代价
- 决策流程:
    1) 承认结论：在不可靠信道上，『绝对共同知识』无法通过有限轮确认达成（每一轮都留下最后一层不确定）。
    2) 用概率工程替代完美协调：n 轮确认后协同成功率 = p^n，算出需要的轮数与冗余（多信使/多路径）。
    3) 若 p^n 无法达标：改变机制——指定单一决策者（独裁）+ 可验证信号，或把行动设计成『任一方单独行动也不致命』。
    4) 把『理解的共同性』也当成信道：用书面、复述确认、可执行演练来降低歧义。
- 判定 checklist（任一不过就别下注）:
    [ ] 需要的是『同时行动』还是『先后行动』？先后可以直接消除协调问题。
    [ ] 信道可靠性 p 是多少？我是否在假设 p=1？
    [ ] 失败的代价是否对称？若只有一方承担，他会不确认就行动。
    [ ] 是否存在叛徒（奸细）？有叛徒时任何协议都可能被破坏（G1）。
- 危险信号: 『我们都说好了』但没有可验证的确认；依赖口头转述的多层指挥链
- 反制: 降级为单点决策+回执；多路径冗余通信；设计容错行动（局部失败不导致全局失败）
- 失败条件: 追求绝对确认 -> 永远不动，错过窗口；假设一次沟通=共同知识 -> 协同失败

## G11 甄别合同菜单（信息租金与扭曲） (Screening Menu / Information Rents & Distortion)
- 脚本入口: `python3 qixia_gt.py screening --file <json>`
- 原书锚点: 生肖飞升对赌合同（晋升=自证）；极乐钱庄三层结构（博彩/彩券/存款）；地羊「四情扇」花道买扇
- 何时用: 我要给不同类型的人提供不同选项，让他们自选并暴露类型 / 对手给我一份『多档合同』，要我选一档 / 需要算：为了让人说真话，我必须让出多少信息租金
- 必需参数: 高/低两类估值 θH,θL；类型先验 p；成本函数（默认 c(q)=q²/2）
- 决策流程:
    1) 写出两类类型的估值与成本，确认单交叉（高类型的边际效用更高）。
    2) 设计菜单 {(q,t)}：低类型拿被扭曲的数量（低于最优）、零租金；高类型拿最优数量、付出信息租金 Δθ·qL。
    3) 检查 IC：高类型不想装低类型、低类型装不起高类型。
    4) 检查 IR：低类型恰好无差异（绑定），高类型有正的租金。
    5) 算扭曲量：qL = θL - (p/(1-p))·Δθ；若 ≤0 则放弃低类型（shutdown）。
    6) 作为被甄别方：识别哪一档是『为零租金设计的陷阱档』，以及能否伪装成低类型套利。
- 判定 checklist（任一不过就别下注）:
    [ ] 菜单的每一档是否都满足 IR？（不满足=逼人退出或摆烂）
    [ ] 低档的数量扭曲是否被我误当成『服务质量差』？那是有意设计的筛选器。
    [ ] 我伪装成另一类型的成本是否低于获得的差额？
    [ ] 是否存在『选高档但只付低档』的执行漏洞（G4）？
- 危险信号: 合同里高档选项附带不可逆义务（自杀条款）；『免费试用』档的退出成本极高
- 反制: 自建菜单反向筛选对手；用可验证凭证替代自述类型；对高档附加可撤销的保证金而非不可逆义务
- 失败条件: 给低类型留了正租金 -> 所有人都装低类型；高档义务不可逆 -> 没人敢选，菜单失效

## G12 终局结算与元博弈（目标函数审计） (Terminal Settlement / Meta-Game & Objective Audit)
- 脚本入口: `python3 qixia_gt.py meta --file <json>`
- 原书锚点: 第337章 道的骗局；第1063章 布局开始；第1082章 最终博弈；第1347章 神之欺诈；十城收集目标与「洗牌」
- 何时用: 所有局都赢了，但不确定赢了之后会发生什么 / 目标本身可能是别人设定的诱饵 / 需要判断『谁在结算这场游戏』
- 必需参数: 目标函数（我在最大化什么）；结算者及其激励；赢的条件与赢之后的下一步
- 决策流程:
    1) 问：这个目标是谁定的？他从中得到什么？（道的骗局：集齐不是出路，是洗牌触发器）
    2) 问：结算者能否在我赢之后改写结果？（规则更改/第三方赌约/抹杀裁判）
    3) 若结算者不可信：把胜利条件改成『结算者也必须履约』的结构（把裁判拖进赌局）。
    4) 设计二层目标：表面目标（赢下这一局）+ 真实目标（获得下一局的规则制定权）。
    5) 留后手：任何单局胜利都必须有『胜利后仍能自保』的备份（底牌/撤退路线/新世界）。
- 判定 checklist（任一不过就别下注）:
    [ ] 我的目标是他给的，还是我自己定的？
    [ ] 赢了之后谁会来收账？
    [ ] 是否存在『赢了反而更危险』的结构？
    [ ] 我有没有第二目标（规则制定权/退出权）？
- 危险信号: 目标由对手单方面宣布；奖励是『集齐X』式的进度条（可被随时改规则）
- 反制: 把结算权抢到自己手里；把胜利条件改成对手无法否认的形式；准备『掀桌』选项（同归于尽的可信威胁，G6）
- 失败条件: 只优化给定目标 -> 成为别人计划里的工具；没有掀桌选项 -> 被无限加价
