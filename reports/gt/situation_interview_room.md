## G2 不完全信息与贝叶斯更新  [bayes]
- 结论：后验已更新
- 动作：选择 EV 最大的动作：保留底牌并试探（EV=80/33）
- 反制：对手可以伪造信号：把『他主动提供的信息』降权，只信他自己要付出代价才能做到的动作（G3）。
- 推导：
  - 先验：P(普通参与者)=7/10, P(生肖的协助者)=3/10
  - 观测『他在规则细节上『从不犯错』』：P(s|普通参与者)=3/10, P(s|生肖的协助者)=19/20 -> 后验 P(普通参与者|s)=14/33, P(生肖的协助者|s)=19/33
  - 似然比 LR = P(s|普通参与者) / P(s|生肖的协助者) = 6/19（LR≈1 时该信号几乎无信息量）
  - 后验下的期望值：
  -   保留底牌并试探: EV=80/33
  -   按普通对手应对（全力压榨）: EV=-40/11
  - 完美信息价值 EVPI = 36/11 - 80/33 = 28/33 -> 花费超过 28/33 去『确认信息』就是亏本买卖
  - 后验接近先验（14/33）：信号信息量不足，需要新信号源（换问题/换观测）。

## G1 囚徒困境与重复博弈  [pd]
- 结论：单次 = 必然背叛
- 动作：先D；若必须合作，先制造重复关系或抵押品。
- 反制：对手若在单次博弈中主动示好，视为在为背叛定价（提高其T）；用公开可观测的惩罚承诺反制。
- 推导：
  - 收益矩阵（我行 / 对手列）：
  -   C 合作 | 3,3 | 0,5
  -   D 背叛 | 5,0 | 1,1
  - 博弈结构识别：prisoner_dilemma
  - 纯策略纳什均衡：(D 背叛, D 背叛)
  - 严格占优动作：我->['D 背叛']；对手->['D 背叛']
  - T=5 > R=3 > P=1 > S=0 且 2R=6 > T+S=5 -> 真囚徒困境
  - 重复博弈临界贴现因子 δ* = (T-R)/(T-P) = (5-3)/(5-1) = 1/2
  - 单次博弈：逆向归纳 -> 唯一均衡 (D,D)，任何口头合作承诺都是廉价的。
  - 我 的混合 maximin 保底收益 = 1（最坏情况下的可保证值，用于设定止损线）

## G12 终局结算与元博弈（目标函数审计）  [meta]
- 结论：高元博弈风险
- 动作：先把结算权/规则制定权拿到手，或把结算者也拖进赌局使其必须履约；同时准备第二层目标（退出权/掀桌可信威胁/新世界）。
- 反制：对手若单方面宣布目标，公开质疑其目标函数并给出现价（谁受益谁定目标）。
- 推导：
  - 风险：目标由他人设定：你可能在完成别人的计划（道的骗局：集齐反招洗牌）。
  - 风险：结算者不可信：赢了也可能被判输。
  - 风险：结算者可改写胜负：终局不是终局。
  - 风险：没有退出/掀桌选项：会被无限加价。
  - 风险：只有单层目标：缺少『胜利后自保』的备份。
  - 元博弈风险分 9/9（≥4 表示『赢了也可能归零』）

## 决策顺序（强制）
1. **S0 规则侦察（G4）** — 抄全规则原文 -> 标注『已定义/未定义/谁解释』 -> 找判定函数、平局、时限、隐藏权限 -> 输出漏洞清单
1. **S1 信息盘点（G2）** — 列状态空间与先验 -> 列可观测信号 -> 算后验与 EVPI -> 决定要不要花代价换信息
1. **S2 结构识别（G1/G5/G8）** — 把局面写成收益矩阵 -> 判 PD/协调/胆小鬼/零和 -> 找纯均衡；无纯均衡再随机化 -> 算 MDF/诈唬比例
1. **S3 顺序与承诺（G6/G7）** — 画博弈树 -> 逆向归纳 -> 剔除不可信威胁 -> 算先手价值 -> 设计自缚承诺；用沉没成本算止损线
1. **S4 机制设计（G11/G4）** — 给人设计菜单让类型自选（低档扭曲、高档付租）-> 校验 DSIC/IR/预算 -> 补规则漏洞
1. **S5 终局审计（G12）** — 追问目标是谁定的、赢了之后谁结算 -> 拿规则制定权/退出权/掀桌可信威胁 -> 设计第二层目标
1. **S6 复盘（G7/G2）** — 记录实际频率与对手偏差 -> 更新先验 -> 判断是过拟合还是可剥削 -> 修正 checklist
