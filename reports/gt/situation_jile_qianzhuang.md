## G8 诈唬频率与底池赔率（阈值/混合）  [bluff]
- 结论：诈唬/防守频率已定价
- 动作：提高诈唬频率：对手弃牌率 9/20 低于 MDF 2/3，任意两张牌下注都是 +EV（EV 增幅 7/20/次）；直到他被迫把跟注率提到 MDF 以上为止
- 反制：对手若诈唬过多 -> 把跟注频率提到 MDF 以上；对手若从不诈唬 -> 只跟价值注，弃掉边缘牌。
- 推导：
  - 底池 P=2，下注 b=1
  - 对手最小防守频率 MDF = P/(P+b) = 2/3：低于这个频率，我用任意两张牌诈唬都是 +EV
  - 我作为下注方的诈唬上限 α = b/(P+b) = 1/3（超过即被『永远跟注』剥削）
  - 均衡诈唬占所有下注的比例 = b/(P+2b) = 1/4；价值:诈唬 = 3 : 1
  - 已知对手弃牌率 f=9/20：纯诈唬 EV = f·P-(1-f)·b = 7/20 -> 必诈
  - 赔付倍数 m=3（如极乐博彩『杀』额外翻倍）：等效底池 6，对手的 MDF 抬升到 6/7 -> 高赔率档位会把对手逼进『必须防守』的窄区间
  - 注意固定成本：极乐博彩每次胜利还要交一颗「道」场地费（除非只赢一颗），名义 +EV 会转负。

## G4 机制设计与规则审计（激励相容/参与约束/漏洞）  [mechanism]
- 结论：机制存在结构性漏洞（DSIC/IR/资金泵）
- 动作：作为设计者：修正违规报告组合的支付/分配；作为参与者：按违规路径套利，或公开要求补丁以换取让步。
- 反制：对手若知道漏洞，会沉默并利用；反制=抢先公开漏洞并提出对自己有利的补丁版本。

## G9 概率分配与随机化设计  [prob]
- 结论：最优胜率 74/99
- 动作：按碗1=1黑+0白的极端集中分配；并确保『随机选碗』由我/裁判执行而非对手选择。
- 反制：若是对手分配：他可以拒绝这种分配或改规则；反制=抢先写下分配规则并要求对方先确认。
- 推导：
  - 黑白各 50/50 颗，两碗均非空，随机选碗后随机摸一颗：
  - 最优分配：碗1 = 1黑+0白（49黑+50白）-> 胜率 74/99
  - 平均分配胜率仅 1/2；最优解把胜率抬高 49/198
  - 原理：把一个几乎必胜的小分支概率拉到 1，代价是另一分支略低于 1 —— 极端集中优于平均。

## G12 终局结算与元博弈（目标函数审计）  [meta]
- 结论：高元博弈风险
- 动作：先把结算权/规则制定权拿到手，或把结算者也拖进赌局使其必须履约；同时准备第二层目标（退出权/掀桌可信威胁/新世界）。
- 反制：对手若单方面宣布目标，公开质疑其目标函数并给出现价（谁受益谁定目标）。
- 推导：
  - 风险：目标由他人设定：你可能在完成别人的计划（道的骗局：集齐反招洗牌）。
  - 风险：结算者不可信：赢了也可能被判输。
  - 风险：结算者可改写胜负：终局不是终局。
  - 风险：没有退出/掀桌选项：会被无限加价。
  - 风险：只有单层目标：缺少『胜利后自保』的备份。
  - 元博弈风险分 9/9（≥4 表示『赢了也可能归零』）

## 决策顺序（强制）
1. **S0 规则侦察（G4）** — 抄全规则原文 -> 标注『已定义/未定义/谁解释』 -> 找判定函数、平局、时限、隐藏权限 -> 输出漏洞清单
1. **S1 信息盘点（G2）** — 列状态空间与先验 -> 列可观测信号 -> 算后验与 EVPI -> 决定要不要花代价换信息
1. **S2 结构识别（G1/G5/G8）** — 把局面写成收益矩阵 -> 判 PD/协调/胆小鬼/零和 -> 找纯均衡；无纯均衡再随机化 -> 算 MDF/诈唬比例
1. **S3 顺序与承诺（G6/G7）** — 画博弈树 -> 逆向归纳 -> 剔除不可信威胁 -> 算先手价值 -> 设计自缚承诺；用沉没成本算止损线
1. **S4 机制设计（G11/G4）** — 给人设计菜单让类型自选（低档扭曲、高档付租）-> 校验 DSIC/IR/预算 -> 补规则漏洞
1. **S5 终局审计（G12）** — 追问目标是谁定的、赢了之后谁结算 -> 拿规则制定权/退出权/掀桌可信威胁 -> 设计第二层目标
1. **S6 复盘（G7/G2）** — 记录实际频率与对手偏差 -> 更新先验 -> 判断是过拟合还是可剥削 -> 修正 checklist
