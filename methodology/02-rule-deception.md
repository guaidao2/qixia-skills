# P2 · 规则欺骗与反欺骗（Rule Deception & Counter-Deception）

> **一句话**：规则层欺骗不是"撒谎"，而是**在对手脑内安装一套错误规则，并让他在错误规则下做出对他自己最优、对你更优的选择**。
> 反欺骗也不是"不信任何人"，而是**建立一套能把"相信"降级为"低成本可验证"的流程**。

| 元数据 | 值 |
|---|---|
| 模式 ID | `P2` |
| 所属层 | L2 规则层 (+ L4 心理层的施压面) |
| 危险度 | 高（反噬成本高，需 P3 的"第二计"护体） |
| 前置 | P1（必须握有真实规则卡，否则骗的可能是自己） |
| 子模式 | D1 隐藏规则 / D2 假规则 / D3 规则武器化 / D4 合同条款工程 / D5 真假规则两难 |
| 原书锚点 | 第8章「摊牌」、第438章「隐藏的规则」、第556章「局中局中局」、第567章「骗亦是信」、第644章「真假规则」、第654章「识破即被骗」、第1327章「最终欺诈？」、第1347章「神之欺诈」、生肖飞升对赌合同全文 |

## 1. 触发条件

- **T1** 规则允许"隐藏部分规则"（原书：兔可破坏、蛇可徇私、**羊可欺诈**、猴可作弊、狗可挑拨）。
  → 只要存在**隐藏许可**，"被隐藏的那条"就是本局真正的胜负手。
- **T2** 对手正在**依据一条你无法核实的规则行动**（他说的规则比原文更好/更坏）。
- **T3** 规则文本**自相矛盾或有冗余条款**（两条"合同期限"、逐条递增的"请马上自杀"）。
- **T4** 你需要**让对手主动做出一个对你不利的动作**，而他理性上不会做。
- **T5** 你已"看穿"对手的骗局——**立刻启动反欺骗流程**，因为"识破"本身常常是第二层诱饵。

---

## 2. 执行步骤（总流程 S1–S7）

无论采用哪个子模式，欺骗的构造都走同一条流水线；**任一步缺失，方案就会在验证或结算时崩掉**。

| 步 | 动作 | 产物 | 判据 |
|---|---|---|---|
| **S1** | **选定欺骗目标态**：确定要让对手相信哪条规则、从而做出哪个动作 | 目标行动树 | 该动作对我方净收益为正 |
| **S2** | **选择子模式**：D1 不告知 → D3 武器化 → D5 两难 → D2 假规则 → D4 条款工程（风险由低到高） | 方案选型 | 能用低风险就不上高风险 |
| **S3** | **收益包装**：把假规则/新选项包装成「对他有利、是他的特权」 | 说辞稿 | 他听完第一反应是「划算」而非「可疑」 |
| **S4** | **自证机制**：借用真实条款的表述风格、权威引用、第三方「无意」证实（**不得伪造证据**） | 证据链 | 他不追问即可自行补全逻辑 |
| **S5** | **保留可否认性**：不留不可撤回的书面痕迹；预备「你误解了」的降级解释 | 降级话术 | 被质疑时损失可控 |
| **S6** | **埋设裁决口**：确保争议出现时由我方或客观设备认定 | 裁决条款 | 对手无解释权 |
| **S7** | **第二层准备**：预判他的「反着来」，在正确路径上留承接 | 第二计 | 他识破第一层后仍落入对我方有利的结果 |

> **顺序铁律**：S1 与 S6 必须**先于** S3–S5 确定。先想好「他要做什么」和「最后由谁裁定」，再去编故事；
> 反过来（先编故事再找用途）就是「为了骗而骗」，必然触发 P2-F1「骗到自己」。

## 3. D1 隐藏规则（Withholding）— 不说谎，只是不说

**原理**：不告知合法，且不告知的**责任在信息接收方**。这是风险最低、最难被指控的欺骗。

**执行步骤**
1. 列出规则全集，标出**"若不告知，对手会做错什么"**的条目（只在决策相关处隐藏，无关处公开以减少怀疑）。
2. 在对手**已经投入成本之后**公布（沉没成本生效，见 P5）——注意：公布时点越晚，对手的"重新决策成本"越高。
3. 预先准备**"解释性框架"**：当被问及为何不早说时，回答"规则一直在那里/我可从没否认过"。
4. 用**公开大量无关细节**掩盖那条关键沉默（信息稀释）。

**原书范例**：猫鼠游戏"猫可在一回合内做多件事"、"水果克房间可打洞"——都是**规则存在但不主动说明**的类型；
朔望月"公共牌可不使用""点数不得大于十六"同理。

**失败条件**
- 对手是"全规则假设者"（假设存在未知规则，先探针后下注）；
- 隐藏的条目**影响契约有效性**（多数真实契约里"未披露"可导致协议无效）；
- 隐藏行为被归因于"恶意"，导致对手放弃合作转向纯对抗（在你需要他配合时致命）。

## 4. D2 假规则（Fabrication）— 植入一条对他有利的错规则

**原理**：人只怀疑**不利**的信息，几乎不怀疑**有利**的信息。所以假规则必须包装成"对对手有利/是他的特权"。

**执行步骤**
1. 选定对手**最想要的收益**（更快赢、更高赔率、豁免、优先权）。
2. 构造一条"他赢的方式"：让假规则**给他一条捷径**，而这条捷径必然经过你要他经过的路径。
3. 设置**自证机制**：让假规则看起来"有依据"——引用真实条款的第 X 条风格、借用权威（"主办方说过"）、或让第三方"无意"证实。
4. 让**他自己的推理**完成剩余工作：假规则只说 60%，剩下 40% 由他的贪婪补齐——**他自己得出的结论，他最难怀疑**。
5. 预留**反悔通道**：当假规则要被验证时，能立刻"澄清"为"你误解了"（可否认性 = deniability）。

**原书范例**：极乐钱庄的"押杀双倍赔付"——表面上是对押注者的馈赠（高赔率），实际上把大量筹码吸到低概率事件上，
而"杀"的判定（生肖死亡，三灯频闪）**由庄家侧的信息与节奏控制**；"只赢一颗不收场地费"同理是小额诱饵。

**失败条件**
- 对手要求**书面化/第三方见证**（假规则一见光就死）；
- 假规则与真规则**逻辑冲突**，被 P1 式交叉验证发现（"两条规则不可能同时成立"）；
- 对手下注前做**成本-收益反算**：若"这么好为什么不早说"，假规则崩塌。

## 5. D3 规则武器化（Weaponized Compliance）— 把条文变成对手的义务

**原理**：所有规则都同时规定"权利"和"义务"。**攻击点不在对手的弱点，而在对手必须遵守的条文。**

**执行步骤**
1. 从规则卡里抽出**对手的强制义务**（不得 X / 必须 Y / 违反则 Z）。
2. 构造一个局面，使对手**只有违反义务才能阻止你**（把他逼进"违规即受罚、合规即失败"的双输）。
3. 保存**可举证的证据**（谁在场、谁记录），使"裁判/第三方"必须承认违规。
4. 给对手一个**体面的退路**（否则他会选择鱼死网破）："你现在认输，我不追究"。

**原书范例（生肖九条守则的每一种武器化）**

| 生肖守则（原文九条） | 武器化方式 |
|---|---|
| 一、不得放弃「生肖」身份（除非死亡） | 逼其在「保住身份」与「活下去」之间二选一 |
| 二、不得摘下面具（除非死亡） | 逼其在必须露脸的场合行动 → 违规或放弃 |
| 三、不可透露真实姓名（除非死亡） | 让其在「报真名」与「弃权」之间二选一 |
| 永不回响 | 制造只有"回响"才能过关的局面 → 用则自毁，不用则败 |
| 永不溃逃 | 让其陷入"必须战至死"的境地，消耗其真实生命 |
| **游戏要有活路** | 若你把游戏做成无解，生肖即违规 → 可用"无活路"逼停/索赔 |
| 不得残杀 | 混入其"不得残杀"的对象（参与者）→ 其杀伤能力被封 |
| 八、参与者赌命胜利后，生肖应**自裁** | 赢它不是杀死它，而是**让它认输**（它自己执行制裁） |
| 九、规则设定后不得私自更改（除非参与者赌命） | 只要不进入赌命，它就**不能改规则**；一旦对手以赌命相要挟，规则层就打开缺口 |
| 赌命规则 6/7：人级制裁为死亡、地级为夺取理智 | 别让地级"赢"：认输、弃权、平局都可能比"输"更好（见 P4-S6「平局算输」） |
| 赌命规则 4：生肖被转为「参与者」时由「玄武」任裁判 | 主动把裁判换成玄武 = 夺走对手的解释权 |

> **关键洞见**：面对"永远遵守规则的强敌"，**最强的攻击是规则本身**。
> 齐夏整部书的核心战术就是"用生肖守则打生肖"。

**失败条件**
- 你对对手守则的**版本过时**（第463章「规则更改」——规则会被改，武器会反向炸膛）；
- 裁判是**对手的人**（"甲方拥有最终解释权"）→ 你举证成功也没用；
- 你把对手逼到"违规也无所谓"的绝境（失去体面退路 → 对手掀桌）。

## 6. D4 合同条款工程（Contract Traps）— 用文本结构杀人

以《生肖飞升对赌合同》为**完整样本**，抽象出一份"恶意条款工具箱"。agent 既可用它做**设计侧审计清单**，也可做**防御侧检查表**。

### 6.1 结构解剖（原合同）

| 部位 | 条款 | 功能 |
|---|---|---|
| 前言 | "本着平等互惠、互相信赖、**生死无悔**原则" | 情绪麻醉：让签字者自愿放弃追责 |
| 标的物 | 1.1~1.5 | 把"进入无限轮回"写得像"岗位说明" |
| **诱饵条款** | 2.1 肉体强化 > 最强参与者十倍；2.2 死后保留记忆并复活 | **先付定金**：先给好处，降低后续条款的警觉 |
| **义务条款** | 2.3 无回响特性；2.4 不得滥杀、不得公报私仇 | 看似约束甲方（保护乙方），实为**违约抓手**：任何不符即可作废 |
| **危险条款** | 3.1~3.6 每条都以"请马上自杀"结尾 | 把自杀**包装成安全操作**（"见到星空""有人走动"→ 自尽） |
| **反侦察条款** | 3.7 "本合同规定内容到『4、合同期限』为止，若乙方发现合同分类超出四条，**请确保本人神志清醒，若清醒，则立刻撕毁合同，并马上自杀**" | **自我指涉陷阱**：识别出陷阱 = 必须死。看穿即死 |
| **矛盾条款** | 4「十年自动作废」 vs 5「永恒，永不作废」 | 两条同名条款互斥 → 解释权归甲方，可任选其一执行 |
| **显形陷阱** | 6~10 「请无视以上内容，马上自杀」「请马上自杀」×4 | **二级诱饵**：让聪明人以为"看到这么荒谬的条款就能免疫"，从而放松对 3.x 的警惕 |
| **兜底** | "本协议一式两份……**甲方拥有最终解释权**" | 结算层收口：一切争议由对手裁定 |

### 6.2 可复用条款模式（16 条"恶意设计语法"）

| # | 语法 | 机制 | 防御问句 |
|---|---|---|---|
| 1 | **前置奖励** | 先给不可撤回的好处，制造互惠压力 | "这个好处，谁付钱？" |
| 2 | **义务不对称** | 一方义务具体、另一方义务模糊 | "我的义务有判定标准吗？" |
| 3 | **重复条款** | 同名条款两次不同内容 | "同名条款以哪条为准？" |
| 4 | **解释权归对方** | 争议由对手裁定 | "谁来裁决我们的分歧？" |
| 5 | **识别即违约** | 发现陷阱本身构成违约 | "我可以指出问题而不受罚吗？" |
| 6 | **道德包装** | "平等互惠""生死无悔" | "去掉形容词后还剩什么？" |
| 7 | **术语未定义** | "神志清醒""思维正常""简单交流" | "这些词由谁测？" |
| 8 | **无限期限** | "永恒""永不作废" | "我如何退出？" |
| 9 | **自动续约** | 未明确拒绝即继续 | "沉默等于同意吗？" |
| 10 | **荒谬显形** | 明显不合理的条款放在末尾 | "荒谬条款是否在掩护中间条款？" |
| 11 | **合并/拆分同名** | 分期、分批、分账户 | "总量与分批的关系？" |
| 12 | **条件触发义务** | "若你见到 X，则须 Y" | "X 的定义是谁给的？" |
| 13 | **举证倒置** | 你要自证清白 | "谁主张谁举证吗？" |
| 14 | **不可抗力扩张** | 对方可随时认定你"不适合" | "'不适合'的判定人是谁？" |
| 15 | **第三方受益人** | 你的行为影响你看不见的第三方（赌约/连带） | "我的失败会让谁受益？" |
| 16 | **签署即默示知悉** | "已充分阅读并理解" | "我能否逐条勾选确认？" |

### 6.3 设计侧：最小可用的"承诺陷阱"公式

```
陷阱 = 一个他非常想要的收益（真）
     + 一条他从未读到的义务（隐藏）
     + 一个只有你能触发的违约条件（权限）
     + 一个把"发现"变成"违约"的条款（反侦察）
     + 一条兜底的解释权（结算）
```

> **重要边界**：本节是**审计框架**。在真实世界中设计此类条款属于欺诈/违法。
> agent 的使用方式：**只做防御侧清单与红队测试**，不得用于制造真实合同陷阱。

## 7. D5 真假规则两难（Rule Paradox Lock）

**原理**：给对手两条**互斥且都可信**的规则，使他的决策瘫痪；或让"验证"本身消耗他。

**执行步骤**
1. 同时释放两条规则 A、B，二者导致**相反行动**；
2. 两条都带"部分证据"（一条有权威背书，一条有观察支持）；
3. 无论他信哪条，你都已准备好对应的一侧；
4. 让他的**验证成本 > 错过窗口的损失**，迫使他带着不确定行动。

**原书锚点**：第644章「真假规则」。同类结构在 D4 的"两条合同期限"中已完整呈现。

**反制**：**用行动验证而非推理验证**——设计一个"无论哪条为真，我都不吃亏"的策略（占优策略先行，见 P4-§6）。

## 8. 失败条件（P2 总体）

| 代号 | 失败方式 | 征兆 | 后果 |
|---|---|---|---|
| **F1** | **骗到自己**：把假规则当真实规则执行 | 你的计划依赖一条"听说"的规则 | 自我毁灭式行动 |
| **F2** | **可否认性丢失**：留下书面/录音证据 | 你说过的每句话都被引用 | 从"欺骗者"变"违约方"，被制裁 |
| **F3** | **骗局需要对手配合**：他的利益一变，骗局失效 | 你的方案依赖他"继续贪婪" | 反被诱导（他假装上钩） |
| **F4** | **层级错判**：你以为在第一层，其实在第三层 | 太顺利了 | 第654章「识破即被骗」：你"反着来"正好走入真正的路径 |
| **F5** | **结算权不在你手**：骗赢了过程，输在结算 | 出现"最终解释权""复核" | 结果被改判 |
| **F6** | **把欺骗当默认**：对所有人说谎 | 无人愿意与你交换真实信息 | 失去所有联盟与情报源（"骗亦是信"的反面） |
| **F7** | **道德/法律越界** | 你的手法需要"对方不知情的实质伤害" | 失去授权与合法性，一切后续行动无效 |

## 9. 反欺骗流程（Counter-Deception Protocol，可直接作为 agent 的子程序）

### 三查法
1. **查原文**：这条规则，我能引用的原句是什么？（不能 → 降级为"声称"）
2. **查判定**：如果它是真的，胜负函数会怎么变？与已知边界冲突吗？
3. **查权限**：谁有权让它生效/失效？谁受益？

### 「识破即被骗」的强制二次校验（第654章）

> 当你确信"我看穿了对方的骗局"时，写下三个问题，全部有答案才可行动：
> 1. **我"看穿"的那一层，是谁希望我看穿的？**
> 2. **如果对方真实目的就是"让我反着来"，我反着来会走到哪里？**
> 3. **有没有一个策略，在"我看穿了"和"我没看穿"两种情况下我都安全？**（有 → 执行它，别赌层级）

### 声誉银行（"骗亦是信"，第567章）

欺骗的最高形态不是让人不信你，而是**让人在该信你的时候信你**。
- 维护"小额守诺"记录（长期成本低、信号价值高）；
- 把"大骗"放在**一次性博弈**中，把"守信"放在**重复博弈**中；
- 一旦声誉破产，你只能靠"规则武器化"（D3）走硬路线，成本急剧上升。

### 反制清单（8 条速用）
1. 只把**可引用的原文**当规则；把一切口述降级为"假设"。
2. 要求**书面化 / 第三方见证 / 逐条确认**。
3. 对"对我有利的规则"**加倍怀疑**（有利信息是首选诱饵）。
4. 计算**给好处的人赚什么**：前置奖励必有代价。
5. 识别**自指条款**（"发现陷阱即违约"）→ 该合同整体作废并退出。
6. 不信"概率性承诺"，只信**已发生的动作**（已付的钱、已押的命、已签的字）。
7. 设**双人复核**：一人读规则，一人读动机（避免同一人既贪又骗自己）。
8. 永远准备**占优策略**：在不确定真假规则时，选一个"两种情况下都不亏"的动作。
