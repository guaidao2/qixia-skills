# P4 · 对赌与承诺设计（Bets & Credible Commitment）

> **一句话**：**承诺的力量来自"不可撤回"，对赌的力量来自"把未来的不确定性换成现在就能判定的结果"。**
> 一个能被撤销的承诺等于没有承诺；一个判定函数含糊的对赌，等于把胜负交给对手解释。

| 元数据 | 值 |
|---|---|
| 模式 ID | `P4` |
| 所属层 | L3 承诺层（+ L1 判定信息） |
| 危险度 | 高（自锁风险） |
| 前置 | P1（判定函数 + 权限矩阵） |
| 原书锚点 | 第120章「生肖飞升对赌合同」、第493章「以赌命做赌注」、第666章「逼退博弈」、第668章「平局算输」、第886章「无法赌命」、第1285章「隔空对赌」、第1318章「三方对赌」、赌命规则八条、生肖九条守则、协同攻击难题（两军问题） |

---

## 1. 触发条件

- **T1** 你需要**让对方相信一件他无法验证的事**（"我会救你""我不会背叛""这东西值钱"）→ 用承诺代替说服。
- **T2** 双方都有**拖延/反悔**的空间，且拖延对你不利 → 引入死线与自动执行。
- **T3** 你面对的是**强者**，对称竞争必输 → 设计**不对称赌局**（用你不在乎的东西赌他在乎的东西）。
- **T4** 对手的优势来自"**等**"（时间、资源、人多）→ 用"逼退博弈"让不作为自动等于失败。
- **T5** 双方**无法直接通信/确认**（隔空、跨城、跨轮）→ 用制度化的第三方或冗余通道替代"确认"。
- **T6** 存在**第三方受益人**：让第三方的行为成为你的抵押品（交叉锁定）。

---

## 2. 对赌的七要素（缺一不可）

| 要素 | 问题 | 原书样本 | 设计要点 |
|---|---|---|---|
| **① 标的** | 赌什么事实？ | 谁能存活、谁先造出字 | 必须是**可观测的单一事实** |
| **② 对手** | 与谁赌？他有无赌命资格？ | 单方声明 + 对方听见即成立；参与者不能拒绝（赌命规则 1 / 参与者守则） | 找**听得见且无资格耍赖**的人；同时确认能否让赌局"不成立"（§4.5） |
| **③ 判定函数** | 怎样算赢？边界呢？ | 两小时 28 字 / 超时字多者胜 | 事前书面化，**平局归属必须写明** |
| **④ 赔率/筹码** | 押什么？值多少？ | 「道」、「理智」、命 | 用**对方更在乎**的筹码 |
| **⑤ 时间边界** | 何时结算？可否延期？ | 十日轮回、一个时辰 | 死线要在**你占优的时点** |
| **⑥ 制裁** | 输的代价由谁执行？ | 地级胜 → 夺取理智；生肖胜负自裁 | 制裁必须**自动/第三方执行**，不能靠对方自觉 |
| **⑦ 裁决者** | 谁来认定结果？ | 青龙、地龙、屏幕、合同甲方 | **裁决权归属决定一切** |

> 检查口诀：**"赌什么 / 怎么算 / 谁裁定 / 押什么 / 何时结 / 谁执行 / 输了多痛"** —— 七问有一问答不上，不要签。

## 3. 执行步骤

### S1 先锁定裁决者（最重要的一步）
对赌的胜负不是"事实上谁赢了"，而是"**谁有权宣布谁赢了**"。
- 优先顺序：① 客观设备/可复算的数据 → ② 中立第三方 → ③ 公开见证的多数 → ④ 对手（最后选择）。
- 原书教训：生肖飞升对赌合同写明"**甲方拥有最终解释权**"，于是所有条款的歧义都自动对乙方不利。
- **操作**：把裁决者写进文本，且裁决者必须**有独立利益**（不能与你对手共谋）。

### S2 判定函数显式化（对自己不利处收紧，对自己有利处保留）
- 所有可能出现的状态都要有结论：**胜 / 负 / 平 / 取消 / 超时 / 一方死亡 / 一方退出**。
- 歧义策略：**对你不利的歧义要澄清；对你可能有利的歧义要留白**——但要评估：留白会否让对手拒签（P2-F2）。

### S3 筹码选择：不对称原则
**用你最不缺的，赌对方最缺的。**

| 你的筹码 | 对方的筹码 | 效果 |
|---|---|---|
| 时间（你可承受长期） | 时间（他有时限） | 拖死他 |
| 命（你有轮回/备份） | 命（他只有一条） | 第493章「以赌命做赌注」 |
| 声誉（你不在乎） | 名誉（他靠名声统治） | 逼他在公众面前表态 |
| 一个可牺牲的队友 | 他的核心战力 | 兑换率极高 |

- **判据**：若双方的"输的痛感"相近 → 这是对称赌局，**资源多者胜**，你不该进。
- **警告**：不对称赌局的前提是**你真的承受得起**，否则构成 F7 自锁。

### S4 不可撤回装置（Commitment Devices）
承诺的可信度 = **撤回成本**。四类装置：

| 类型 | 手段 | 原书对应 |
|---|---|---|
| **物理** | 交出真身/人质、毁掉退路、公开自缚 | 拒令即"溃逃之将，当场抹杀"（仓颉棋） |
| **制度** | 合同、托管、第三方见证、押金 | 生肖飞升对赌合同 |
| **自动** | 死线到期自动执行、条件触发 | "地级胜利 → 夺取理智"；"放过一个即抹去一名队友" |
| **心理** | 公开宣言（面子抵押）、当众立誓 | 齐夏多次公开宣告"我有第二计"以稳定军心、抬高对手的心理成本 |

- **反直觉要点**：装置的威力来自**"我无法反悔"**这个事实被对方**看见**。装得再狠，看不见就等于没有。

### S5 时间作为武器（逼退博弈，第666章）
- **规则形态**：**"不作为 = 失败"**。对方越等越亏，于是必须在你选定的时点上行动。
- 设计三步：① 设定一个对你有利的结算时点；② 让拖延在该时点后自动惩罚对方；③ **公开这个机制**（否则他不信，就会拖）。
- 原书样本：青龙"四天杀八个地级生肖，放过一个就抹去一名队友"——倒计时 + 连坐，把"等待"变成净损失。

### S6 改变平局归属（第668章「平局算输」）
- 平局往往是强者的保底方案。**把平局的代价转移给他**，就翻转了整张桌子。
- 公式：`双方都不行动 → 判定为 X 方输`。若 X = 对手，则他被迫先动（先动者先暴露）。
- 应用清单：
  - "若到时双方都未达成条件，判**资源多的一方**失败"（惩罚优势方）；
  - "若无法判定，视为**违约**"（惩罚拖延方）；
  - "若双方同时达成，以**先完成时间**为准"（惩罚后手）。

### S7 预留退出条款（自保）
- 你必须有不触怒对方、又不损失的退出方式：**认输/弃赛/平局/转让/延期**。
- 原书现成范本：**赌命规则第 8 条——双方都未杀死对方，视为赌命失败，无人被制裁**。
  → 这意味着"**不杀**"是合法解约。读懂这类"兜底条款"，等于找到逃生门。

## 4. 高阶形态

### 4.1 隔空对赌（第1285章）
双方不在同一空间/无法直接验证对方行动时，如何设立有效赌约？
- **三层设计**：① 一个**共享的可观测信号**（第三方、屏幕、公开结果）；② 一个**自动触发的制裁**（不依赖任一方执行）；③ **冗余通道**（多路信号，避免单点失效）。
- 本质：**把"确认对方"替换成"确认信号"**。

### 4.2 三方对赌（第1318章）
引入第三方，使**任何两方都无法单独撤退**（交叉锁定）。
- 结构：A-B、B-C、C-A 三个赌约同时成立，任一方的背叛都会被第三条赌约惩罚。
- 用途：**锁定联盟**、**防止背后交易**、**把弱者的安全建立在强者的互相牵制上**。
- 风险：任一条先被解除，另两条立刻变成劣势（连锁崩塌）。

### 4.3 二阶承诺：用自己去破坏第三方的赌约（地龙样本）
> 地龙此前与青龙赌**自己的死亡方式**；随后地龙向文巧云**认输自杀**，使青龙的赌约**失败**，
> 从而迫使青龙放过失败的楚天秋一方。

- 结构：`我的行为 → 改变第三方赌约的判定 → 改变第三方的行为`。
- 这是**承诺的杠杆**：一个人的死，能兑现一整支队伍的生存。
- 抽象条件：① 存在一个"把我的行为纳入判定"的赌约；② 我的行为对该判定有**决定性影响**；③ 第三方**必须履约**（其违约成本 > 收益）。

### 4.4 协同攻击难题（两军问题）：不可确认环境下的承诺

**问题**：双方约定同时进攻才能胜，但任何"确认"都需要再确认，**无限递归，永远无法确知对方已知**。

**原书的解法**：**"整个山头的人一起当传令兵"**——把"确认"替换为**冗余投递**，使至少一半消息必然到达，
于是协同的失败概率被压到可接受水平（而非 0）。

抽象出四条可复用原则：

| 原则 | 说明 | 落地动作 |
|---|---|---|
| **① 消除不了不确定性，就压低它的价格** | 把"必须 100% 确定"改为"概率可承受" | 计算"失败概率 × 失败损失 < 收益"即执行 |
| **② 冗余通道 > 增加确认轮次** | 确认轮次只增加延迟，冗余增加成功率 | 多路径、多信使、多信号 |
| **③ 让行动本身成为确认** | 不可撤回的动作是唯一"无需回执"的信号 | 提前小规模发动、公开可观测的预备动作 |
| **④ 改变目标结构** | 不必"同时" → 只要"先动者能活到后动者到达" | 把同步问题转为**耐久问题**（第666章逼退的镜像） |

> **结论句（可直接引用进 skill）**：不要试图在不可靠信道上达成完美共识，而要让策略在**部分失败**下仍然存活。

### 4.5 赌命的门槛与免疫（第886章「无法赌命」）

**先纠正一个常见误读**：赌命**不是双方同意制**。已确认的规则是：

- 赌命规则 1：**一方表现出明确意愿且另一方听到其赌命要求时，即视为「赌命开始」**（单方声明即成立）；
- 参与者守则：**参与者不能拒绝赌命**；
- 赌命规则 2：若由**生肖方**提出，可临时改变规则。

所以防线**不是"拒绝"**（你没有这项权利），而是**"让赌命无法成立"**：

| 免疫路径 | 依据 | 操作 |
|---|---|---|
| **让标的不存在** | 赌命需要一个可判定的"游戏结果" | 提前结束/取消游戏、让标的物毁掉（参见送信人"标的物毁掉则义务解除"） |
| **让对手不具赌命资格** | 赌命需"一方向另一方"提出 | 让对手在规则上不再是"生肖"或不再是"对方"（结盟、身份变更、被第三方接管） |
| **抢先重置裁判** | **赌命规则 4**：若赌命发起时「生肖」不作为游戏参与者，则**改变其身份使其成为「参与者」，并由「玄武」担任新裁判** | 主动把局面推入"生肖也是参与者"的形态（四情扇即此结构的实例），把裁判从对手一方换成玄武 |
| **降低制裁等级** | 赌命规则 5–7：人级 → 死亡；地级 → 夺取理智；等级越高制裁越重 | 与低等级者赌、避开天级 |
| **利用兜底条款** | 赌命规则 8：双方都未杀死对方 → 赌命失败，无人受制裁 | 在"杀死"这一判定上做文章（不可杀死 / 已死 / 第三方代杀） |

> **第886章「无法赌命」**只提供了标题级线索：存在某种"赌命无法成立"的状态，值得作为**防线研究方向**；
> 其具体机制未在资料中给出，**不得臆断**。可确认的是：**"拒绝"不是可行的防线，"让赌局不成立"才是。**

## 5. 失败条件

| 代号 | 失败方式 | 征兆 | 后果 |
|---|---|---|---|
| **F1** | **判定含糊** | 你说不出"平局怎么算" | 结算时被对手解释成他赢 |
| **F2** | **承诺不可见/可撤回** | 你没有押上任何无法收回的东西 | 对手不信 → 赌局不成立，威慑归零 |
| **F3** | **对称赌局** | 双方筹码与痛感相当 | 资源多者胜，你必输 |
| **F4** | **时间由对方控制** | 结算时点不由你定 | 被迫在劣势时点结账 |
| **F5** | **裁决者是对手的人** | 出现"最终解释权" | 赢了也被改判 |
| **F6** | **第三方拆台** | 你的抵押依赖一个会变卦的人 | 交叉锁定反向锁死你 |
| **F7** | **自锁**：赌注超过承受阈值 | 你开始"希望对方不要接受" | 你把刀柄递给了对方 |
| **F8** | **承诺降级** | 事后被解释为"玩笑/比喻/气势" | 你的所有威慑从此贬值（声誉破产） |
| **F9** | **完美的同步幻想** | 你的计划要求"双方 100% 同时" | 两军问题：永远不行动或单方面送死 |

## 6. 反制手段（当对手向你提出对赌）

**签约前七问（逐条口头回答，答不上就拒签）**
1. 你的**裁决者**是谁？他和你什么关系？
2. **平局、超时、一方退出**分别怎么算？
3. 你押的**不可撤回的东西**是什么？（只押嘴的人不配对赌）
4. 我的**退出成本**是多少？你的呢？
5. 这个赌约**让哪个第三方受益**？（找隐藏受益人）
6. **时间**由谁控制？能否被单方面延长？
7. 如果我现在**拒绝**，会发生什么？（注意：参与者不能拒绝赌命，所以真正要问的是——**对方能否让赌局"不成立"**？）

**战术反制**
- **拉平承诺**：要求对方也押上对等的不对称筹码（"你先押，我再考虑"）。
- **改写平局**：把"平局算我输"改为"平局双方各付一半"或"平局重赛但不换筹码"。
- **争夺裁决**：要求引入可复算的客观结果（数据、录像、第三方），拒绝"解释权"。
- **延迟签约**：时间压力是对手的武器，也是你的——**任何催促都是信号**。
- **免疫式防御**：赌命一经声明即成立且参与者不能拒绝，故防线是"让赌局无法成立"——提前结束标的、让对手失去赌命资格、或抢先触发「生肖转为参与者 + 玄武任裁判」的重置结构。
- **破对称**：若对方要求对称赌局，主动提出"加一个不对称条款"（如"我输我付双倍"）以换取他更在乎的东西——**用你不在意的额度买他不能失去的东西**。
- **识别"平局算输"**：一旦发现对方在定义平局归属，先问"为什么是他定义"。
- **两军问题反制**：对方要求你"精确同步"时，改为提出**冗余方案**或**耐久方案**，你既显得专业，又拿走了"必须完美同步"的压力。

## 8. 与其他模式的接口

- ← **P1**：没有判定函数就没有对赌；没有权限矩阵就不知道谁能改判。
- ← **P2**：对赌文本是 P2-D4 条款工程的合法应用场（同为"审计"用途）。
- → **P3**：对赌是连环计中"层的锚"——每一层用赌约固定，防止对手在层间跳转。
- → **P5**：赌局成立后，胜负常常由"谁先崩"决定，而非计算（沉没成本 + 攻心）。
