# P1 · 规则侦察与隐藏规则识别（Rule Recon & Hidden-Rule Discovery）

> **一句话**：在你行动之前，先把"这张桌子上到底有几套规则"变成一份可引用的**规则卡**；
> 一切谋略都建立在"我知道的规则 ≥ 对手以为我知道的规则"之上。

| 元数据 | 值 |
|---|---|
| 模式 ID | `P1` |
| 所属层 | L1 认知层 + L2 规则层（+ L5 元层扩展） |
| 危险度 | 低（可安全重复使用） |
| 前置 | 无（这是所有其他模式的前置） |
| 后继 | P2（欺骗）、P4（对赌，需先知道判定函数） |
| 原书锚点 | 第438章「隐藏的规则」、第460章「未曾提及的规则」、第463章「规则更改」、第619章「漏洞」、第644章「真假规则」、第831章「规则盲点」、第1237章「漏洞百出」 |

---

## 1. 触发条件（何时必须做）

满足任意 2 条即启动完整侦察流程：

- **T1** 进入新场景 / 新游戏 / 新合同 / 新平台 / 新组织，而你只拿到了**摘要或口头规则**。
- **T2** 规则由**第三方转述**（队友复述、广播播放、上级口述）而非可反复阅读的原文。
- **T3** 存在**裁判 / 主办方 / 甲方 / 平台**，且其利益与你不同。
- **T4** 对手表现出**与规则不相称的自信**（敢下重注、敢说"你不会赢"、敢让你先手）。
- **T5** 规则文本出现**自指、矛盾或道德劝诱**："甲方拥有最终解释权""请立即自杀""若发现分类超过四条请撕毁本合同"。
- **T6** 目标极其清晰、所有人都被要求收集同一样东西（→ 立刻做**元层审查**，见 §7）。
- **T7** 你正准备用的策略**依赖"对手不知道某事"**（依赖信息差之前，必须先确认规则层没有把这件事公开）。

## 2. 执行步骤

### S1 冻结原文（Freeze）
把规则变成**可引用、可回读、时间戳固定**的东西：抄录、截图、录音、复述回执。

- 反例（原书）：仓颉棋的正式规则"通过房间内的广播传递给参与者"——**不进房间就听不到全集**；
  面试房间合同"一式两份，甲乙双方各持一份，**甲方拥有最终解释权**"。
- 产物：`rules_raw.md`，每条规则带来源（谁说的 / 什么形式 / 何时 / 能否再读）。
- 判据：**任何"我没见过原文"的规则，不允许作为下注依据。**

### S2 词表审计（Term Audit）
抽出全部**名词、量词、判定词**，逐一标记「已定义 / 习惯性理解 / 完全未定义」。

原书中反复被利用的未定义词清单（可直接作为模板）：

| 未定义/半定义词 | 原书被利用方式 |
|---|---|
| 「字」「偏旁」 | 仓颉棋允许提交"仈""㑟"等非标准字，只要写得出**同音字**即可得分 |
| 「同一时刻」「同时」 | 两军问题的死结：无人能确证"对方已知我会进攻" |
| 「存活」「杀死」 | "未杀死对方 = 赌命失败"，于是"逼对方自杀"既不违规也不算赢 |
| 「回合」「夜晚 / 白天」 | 猫鼠游戏：猫"每回合可做的事不止一件，只要有饱腹值便可一直行动" |
| 「最接近十六」「不得大于十六」 | 朔望月：**大于 16 爆牌**，故大牌是垃圾牌 |
| 「重合」「意见不一」 | 极乐钱庄彩券"无人重合则滚入奖池"；说谎者需"意见统一"才算胜 |
| 「运送」「送到」 | 送信人：奸细"必须三分钟内送到，**除非该物已毁掉**" |

### S3 判定函数提取（Win Function）
把胜负写成一个函数并**枚举所有输入与边界**：

```
win(state) → bool
必须覆盖的边界：平局？无人达成？时间耗尽？一方全灭？中途退出？裁判介入？结算后再改判？
```

原书五组关键判定函数（作为"边界先查"的模板）：

| 局 | 判定函数 | 边界陷阱 |
|---|---|---|
| 仓颉棋 | 两小时先得 28「字」者胜；超时则**字多者胜**；败方全灭 | 时间是第三条胜负线，不只是"先到" |
| 朔望月 | 手牌+公共牌点数**最接近 16** 者胜，>16 爆牌 | 正序比大小的直觉被反转 |
| 跷跷板（人龙） | **未被淘汰即胜** | 什么都不做就是最优 |
| 赌命（通则） | 双方都未杀死对方 → **视为赌命失败，无人被制裁** | "不杀"是合法的解约方式 |
| 地马时刻 | 活下来即胜，无奖励 | 胜利与收益脱钩时，不必争夺名次 |

> **金句**：判定函数比策略更值钱。改不了策略，就去改判定函数（见 P4-S6「平局算输」）。

### S4 权限矩阵（Who May Cheat）
列出**谁被允许不遵守，以何种方式不遵守**。这是原书最锋利的一层设定：

> 「生肖」可以隐藏部分游戏规则：**兔可以「破坏」，蛇可以「徇私」，羊可以「欺诈」，猴可以「作弊」，狗可以「挑拨」。**

| 角色类型 | 被允许的"合法作弊" | 应对方式 |
|---|---|---|
| 兔（逃脱类） | 破坏场地/道具 | 不依赖固定通道，准备备用路线 |
| 蛇（问答类） | 徇私、改判回答 | 要求书面/可复核的判定 |
| 羊（欺诈类） | 撒谎、误导、假规则 | 只信"原文"，不信"讲述" |
| 猴（智力类） | 作弊（暗改规则/道具） | 记录并交叉验证，抓现行 |
| 狗（合作类） | 挑拨（分化你方） | 预置队内协议与叛徒检测 |

- **推论**：你面对的**不是规则，而是"规则 + 该角色的作弊许可"**。见到面具/职位/身份，先查其作弊许可。
- 另有一层更狠的：**主办方本身也是参与者**。四情扇的隐藏规则——"地羊在此游戏内属于「参与者」"，
  意味着"生肖不得残杀参与者""胜负自裁"等约束对它失效，且它可以被当作普通参与者攻击/交易。

### S5 未定义处猎取（Leverage Hunt）
系统扫描"**字面允许但意图禁止**"的动作。原书现成漏洞样本：

1. **黑门 = 场外**：仓颉棋高墙七扇门只有红色可进，黑色"通向场地之外，进入即视为离开游戏场地（退出游戏）"。
   → 一个"看起来是陷阱"的选项，实际是**合法弃赛通道**；也可用于把对手骗进门。
2. **尺寸上限即权限边界**：送信人粉碎机可粉碎信、钥匙、锁，但"由于尺寸限制，「铁盒」丢不进去"。
   → 寻找对手"能力覆盖不到的形状/大小/频率"。
3. **角色豁免**：木牛流马"被打到会淘汰，**但推车的人不受影响**"。→ 换角色即可免疫伤害（并让最强的人去推车）。
4. **义务的自动解除**：奸细"必须三分钟送到，**除非那个东西已经毁掉了**"。
   → 若做不到，就**销毁标的物**使义务失效（合法的"毁约"）。
5. **触发式补位**：仓颉棋"中途不可交换「字」，**只有丢失「字」时**才可把多余的「字」安排到空余人身上"。
   → 一个被禁止的操作，往往藏着一个"触发条件"，主动制造触发条件即可解锁。
6. **重复与拆分**：极乐钱庄"若获胜者只赢得一颗「道」，则**不收取场地费**"。
   → 把大额操作拆成免佣的小额操作。
7. **无人中奖即滚池**：彩券"若无人重合，则筹码计入奖池，等待第二天开奖"。→ 等待 = 获取他人沉没的筹码。

### S6 定向探针（Probe）
**不要猜，要测。** 用一个**你输得起的成本**去触碰边界，并预设两种结果的解释。

| 探针设计要点 | 说明 |
|---|---|
| 成本可控 | 只赢一颗「道」级别的投入；一次小规模试探 |
| 可观测 | 结果必须能与你预设的两种假设区分开 |
| 可否认 | 不要让对手从探针里反推出你的真实假设 |
| 有记录 | 探针结果写入规则卡，团队共享 |

- 原书隐藏规则的典型形态——**都是"发现即破解"的机关**：
  - 猫鼠游戏：「水果与房间相克 → 房间失去上锁能力 → 可打洞逃脱」（五行相生相克是钥匙）；
  - 灾厄年：「**鞭炮辞旧岁**」只有让代表冬季的**蓝色房间**使用才有伤害；
  - 狭路相逢（地虎）：判定是"**不从独木桥掉下去即出局**"这类反向规则；
  - 黑熊狩猎（地牛）：铁板存在**两解**；
  - 蓬莱（地兔）：十六个房间 + **八仙神通**是隐藏规则。
- **判据**：探针结果与显式规则**完全一致 → 放弃该假设，别自我说服**；出现无法解释的例外 → 记为候选隐藏规则，追加第二次验证。

### S7 固化与共享（Freeze & Share）
输出 `rulesheet`（见 §3 模板）并**向全队广播**。原书中"信息共享"直接决定生死：

- 「不插队」：20 秒公开沟通时间内必须形成**可执行的无声协议**；
- 仓颉棋：字必须送到主帅，**运输线的信息（谁在哪、谁有字）全队必须共知**。

## 4. 失败条件（Failure Modes）

| 代号 | 失败方式 | 可观测征兆 | 后果 |
|---|---|---|---|
| **F1** | **摘要下注**：只看结论不看原文 | 你说不出规则原文的出处 | 被"最终解释权"随意拿捏 |
| **F2** | **惯例替代规则**：把"通常怎么玩"当成规则 | 开始使用"按理说""一般都是" | 对手用一条明文条款合法碾压你 |
| **F3** | **侦察成本 > 收益**：为验证一条猜测押上全队 | 探针成本超过该漏洞的期望收益 | 验证成功也亏 |
| **F4** | **探针暴露**：试探被对手观测并反向利用 | 对手开始"配合"表现异常 | 对手伪装成有隐藏规则，诱你按错误假设行动 |
| **F5** | **忽略结算层**：游戏内赢了，裁判改判 | 出现了"解释权""最终裁定""追加条款" | 胜利被没收，甚至反转为失败（第463章「规则更改」） |
| **F6** | **把漏洞当承诺**：假设漏洞永远可用 | 你只有一条路径 | 裁判封堵漏洞，你无 Plan B（违反"第二计"铁律） |
| **F7** | **只侦察不共享**：你知道，队伍不知道 | 队友在按显式规则行动 | 团队因信息不对称自灭（不插队、仓颉棋都靠协作） |
| **F8** | **目标不审**：只查"怎么赢"，不查"赢了会怎样" | 无人能回答"赢了之后谁结算" | 走进"道的骗局"式陷阱（见 §7） |

## 5. 反制手段（当对手在用 P1 对付你）

1. **规则公开化**：把"口头/惯例"逼成"书面/公开念出"。对手的隐藏规则优势来自**不可回读**，一旦被录音/复述，就变成双方共有信息。
2. **主动争夺解释权**：在对手之前，用"我们按字面理解执行"的方式**先定义未定义处**。谁先给词下定义，谁就赢下这一层。
3. **只信两种信息**：可验证的原文，和**有代价的声明**。对手说"我知道隐藏规则"→ 要求他"押注证明"（见 P4）。
4. **反向解读其下注**：对手越是重注、越是催促你行动，说明他掌握的信息越真。**把对手的下注当作信号读取器**（信号博弈）。
5. **设置规则变更告警**：每回合重读关键判定项与"最终解释权"归属，一旦变更立即进入 P2-D3「规则武器化」的改判对抗。
6. **封堵漏洞前先让他用一次**：若你已知某漏洞，可选择**观察对手使用再做记录**，用"违规证据"换取后续谈判筹码（适用于有裁判的博弈）。
7. **制造假的隐藏规则**（P2）：让对手以为存在一条对他有利的隐藏规则，使其按错误假设行动。
8. **用第三方踩坑**：把探针交给**成本最低的成员**（最弱、最可替代、或已被怀疑者），保护核心信息。

## 7. 元层扩展：目标审查（Goal Audit）

P1 的最高形态不是找游戏漏洞，而是**审查"为什么玩这个游戏"**。

> 原书最大的一次反转为：五城收集的「道/玉/涡/勾/索」并非通行证——**集齐反而招来「洗牌」**。

**目标四问（发现 P1 元层漏洞的标准动作）**：
1. **谁定义了这个目标？** 是裁判、对手，还是和我利益一致的人？
2. **达成目标后，谁的处境会变差？** 若某人的最优策略是"阻止我达成"，那这个目标可能就是为他设计的。
3. **有没有人已经达成过？** 若无先例，却人人确信可行 → 这是信仰，不是事实。
4. **目标函数的口径由谁计量？** 计量者 = 真正的庄家（"道"的计数、屏幕的"总红/总绿"都是他写的）。

**判据**：若四问中有任意两问无法回答，**暂停执行，先做元层侦察**——这比任何战术优化都更省命。

## 8. 与其他模式的接口

- → **P2**：规则卡中的 D 段（权限矩阵）直接决定你能用哪种欺骗；E 段的漏洞清单是 P2 的弹药。
- → **P4**：规则卡 C 段（判定函数）是对赌设计的唯一合法输入。**不知道 win(state) 就签约定 = 自杀**。
- → **P5**：对手的"未定义词"往往也是他的恐惧点（他在意哪个词，就在意哪件事）。
- ← **P3**：连环计中每一层都要重复一遍 P1，因为层与层的规则可能不同。
