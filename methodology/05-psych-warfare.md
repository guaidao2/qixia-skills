# P5 · 心理战与攻心（Psychological Warfare）

> **一句话**：人不会因为"算不赢"而认输，只会因为"**不想再算下去**"而认输。
> 攻心的目标不是改变对方的计算，而是**改变他计算的输入**——恐惧、贪婪、面子、执念、已经付出的代价。

| 元数据 | 值 |
|---|---|
| 模式 ID | `P5` |
| 所属层 | L4 心理层（作用于 L1~L3 的输入） |
| 危险度 | 高（易反噬、易越界） |
| 前置 | P1（必须知道对方的真实在乎什么，否则攻心=瞎打） |
| 原书锚点 | 第2章「说谎」、第60章「心理战」、第75章「攻心计」、第250章「沉没成本」、第278章「囚徒困境」、第647章「连环攻心」、第654章「识破即被骗」、第666章「逼退博弈」、第668章「平局算输」 |

---

## 1. 触发条件

- **T1** 双方**理性上打平或你处于劣势**，但对方有明确的情绪弱点（怕死、贪财、爱名、重感情）。
- **T2** 对手**必须在时限内做决定**（时间压力天然放大情绪）。
- **T3** 对手**已经投入了大量不可撤回的成本**（沉没成本可用）。
- **T4** 对手**骄傲**（"他以为自己看穿了你"是最廉价的入口）。
- **T5** 你有能力**控制节奏**（谁决定何时说话、何时结算、谁先开口）。
- **T6** 你**必须让队友继续战斗**（攻心不只对敌，也对内：军心是最容易被忽略的战场）。

## 2. 五个情绪杠杆（按可靠性排序）

| # | 杠杆 | 触发语式 | 原书样本 | 反制难度 |
|---|---|---|---|---|
| 1 | **沉没成本** | "你已经投了这么多，现在退出就全废了" | 第250章；极乐钱庄彩券滚池 | 中（需外部视角） |
| 2 | **恐惧 / 未知** | "你也可以不选，结果自负" | 天蛇时刻（答错即爆头） | 中 |
| 3 | **面子 / 公开承诺** | "当着你的人再说一遍" | 生肖不得透露真名（身份即软肋） | 高 |
| 4 | **贪婪 / 稀缺** | "这个窗口只有现在" | 极乐钱庄押「杀」双倍 | 高 |
| 5 | **执念（爱/恨）** | "你其实不在乎赢，你在乎的是他" | **齐夏的弱点：余念安** | 极高 |

> **第 5 条要特别注意**：执念是最强的杠杆，也是**最危险**的——它会让使用者失去自我控制。
> 齐夏全书最大的破绽就是余念安：他的敌人反复以此为入口。**任何谋略者的第一风险，是自己未处理的执念。**

## 3. 执行步骤

### S1 画像（Card）：先知道他在乎什么
从 P1 的观察通道收集四类证据，不要靠猜：

| 观察点 | 推断 |
|---|---|
| 他优先保护谁 / 什么东西 | 真实优先级（恐惧与爱的位置） |
| 他在什么场合**改口** | 面子的边界 |
| 他如何对待"已经输掉的东西" | 沉没成本敏感度 |
| 他赢的时候说什么 | 自我叙事（最容易被利用的信念） |

**禁止**：在没有证据的情况下使用"人性通用弱点"（对高手无效，且会暴露你的意图）。

### S2 建立"必要性"（先立框架，后谈条件）
- 让对方相信**必须现在做决定**（时间）、**只能在你给的选项里选**（框架）、**不选更糟**（默认损失）。
- 原书：青龙的"四天杀八个地级生肖，放过一个就抹去一名队友"——倒计时 + 连坐，把"等待"变成净损失。

### S3 沉没成本累积（Escalation）
1. 先要一个**极小且无害**的让步（登门槛）；
2. 再要一个**公开**的承诺（面子抵押）；
3. 再要一个**不可撤回**的投入（时间/资源/盟友）；
4. 此时提出真实要求——他已经无法回归"零成本退出"。
- **关键**：每一步都要让他**自己说出来**（自我说服 > 外部说服）。

### S4 节奏控制（Pacing）
- 谁先开口，谁先失去耐心红利。**沉默是最便宜的压力**。
- 连续施压要**不给恢复期**（第647章「连环攻心」）：每当他重建一点信心，就在那个瞬间再打掉它。
- 反之，**不要连续攻击超过三次**——超过之后，对方会从"焦虑"切换到"鱼死网破"（见 F1）。

### S5 留退路（赦免通道）
- 必须给对方一条**体面的退出路径**："你现在认输/退出/改主意，我不追究"。
- 没有退路的人会**掀桌**——这不是勇敢，是绝望下的理性选择（他的期望收益在"同归于尽"里反而更高）。
- 原书对照：仓颉棋"拒令即当场抹杀"之所以有效，是因为**接令（生）与拒令（死）**都明确，恐惧有出口；
  而"黑门 = 退出游戏"则是一条**合法逃生门**，降低了所有人掀桌的概率。

### S6 对内攻心（军心）
- 团队崩的常见顺序：**信息不透明 → 猜疑 → 私下的最优选择 → 集体崩溃**。
- 三个动作：① 定期公开"我们已知/未知/正在做"；② 给每个人一个**专属的不可替代的位置**（地位=忠诚）；
  ③ 主动承认一次困难（示弱的可信度 > 永远乐观）。
- 反面样本：青龙"放过一个即抹一名队友"——用连坐制造**内部互害**，是最廉价的瓦解术。

## 4. 高阶技巧

### 4.1 识破即被骗（第654章）
让对方"看穿"你的一层假意图，他就会**按反方向行动**，而正方向恰好是你的真实路径。
- 执行要点：假意图要**符合他的偏见**（他认为你贪婪，就给他贪婪的剧本）。
- 反制：见 §6-②（强制二次校验）。
- **升级版：扮成"漏洞百出的骗子"**（原书：某个角色"擅长将自己装扮成一个漏洞百出的骗子"）。
  主动示弱、故意露出小破绽 → 对手的"识破"本身就是被安排的情节，他会**低估你的真实能力**。

### 4.2 逼退博弈（第666章）
把"不作为"定义为失败 → 对方的保守策略自动转化为劣势。
- 与 P4-S5 联动：**机制公开 + 死线明确**，恐惧才会生效。
- 升级：把死线设在**他最不愿行动的时刻**（例如他刚投入大量资源后）。

### 4.3 平局算输（第668章）
- 心理层效果：剥夺"保守保底"的心理安全感，迫使他主动出手。
- 副作用：对手可能在慌乱中做出**非理性的高风险动作**——**这既是机会也是风险**（你要有承接方案）。

### 4.4 囚徒困境（第278章）：分化
- 只要让双方**无法确认对方的选择**，且背叛的即时收益 > 合作的长期收益，联盟必然破裂。
- 制造手段：切断通信（信息隔离）、提供"只对一人"的私下交易、让背叛**无法被观测**。
- 反制：**重复博弈 + 声誉 + 可观测的承诺**（P4），把单次博弈转成长期博弈。

### 4.5 真假话问询（信息压缩式提问）
**场景**：你只能问一个问题，但要同时确定两件事（例如"哪碗有黑子"+"谁在说真话"）。
- 结构解法：**元问题（meta-question）**——让问题**指涉回答行为本身**，而非只指涉事实。
- 原书样本（人蛇「是与非」）：*"假如我的下一个问题是『你会不会拉下拉杆』，你的回答会跟这个问题一样吗？"*
  → 无论对方是否说谎，答案都被约束为"必须拉杆"。**把欺骗的可能性编码进问题里，使真话与谎话收敛到同一结果。**
- 通用模板：
  - `如果我问你"P 是否成立"，你会回答"是"吗？`（双重否定，抵消说谎者）
  - `你（说真话者/说假话者）会如何描述"对方会怎么回答 Q"？`（转述结构）
  - `"P 与 Q 是否同真假"`（把两件事编码为一个二值答案）
- 适用前提：说谎者**必须说谎**（规则强制），否则元问题失效。**先确认约束是"强制"还是"倾向"。**

### 4.6 攻心工具箱（12 句通用话术，谈判/红队场景）

| # | 目的 | 话术 | 注意事项 |
|---|---|---|---|
| 1 | 建立框架 | "我们先确认一下，这件事的目标是什么？" | 抢定义权 |
| 2 | 制造时间压力 | "这个方案我们只能保留到明天。" | 必须是**真实的**，否则可信度破产 |
| 3 | 沉没成本提示 | "已经投入的部分，你希望它作废吗？" | 慎用，容易激起对抗 |
| 4 | 面子上桌 | "这话你愿意让你的团队听见吗？" | 有第三方在场时慎用 |
| 5 | 稀缺 | "这个位置只有一个。" | 稀缺必须可验证 |
| 6 | 反向沉默 | （听完后停顿不回应） | 最长不超过 10 秒 |
| 7 | 体面退路 | "你现在改主意，我当作没发生过。" | 必须真的执行，否则失效 |
| 8 | 拆解动机 | "你要的是赢，还是要他输？" | 分离"目标"与"情绪" |
| 9 | 给对手台阶 | "换我在你的位置，我也会这么算。" | 共情 ≠ 让步 |
| 10 | 要求自我承诺 | "你自己说，几号之前完成？" | 让对方报数 |
| 11 | 引入第三方 | "我们让数据和记录说话。" | 把裁决权从对方手里拿走 |
| 12 | 亮出底牌的一半 | "我还有一件事没说。" | 只有**真的**有后手时才用（P3-S6） |

## 5. 失败条件

| 代号 | 失败方式 | 征兆 | 后果 |
|---|---|---|---|
| **F1** | **逼到墙角**：没留退路 | 对方开始说"那大家一起死" | 对手选择同归于尽，你失去一切可赢的东西 |
| **F2** | **手法被识破**：对方看穿你在操纵情绪 | 对方开始"配合表演" | 信任永久破产，之后所有信息都不可交换 |
| **F3** | **对象不适配**：对手是彻底理性者/彻底疯癫者 | 你的施压毫无反应 | 时间被浪费，窗口关闭 |
| **F4** | **节奏过慢**：攻心需要时间，但机会有窗口 | 你还在铺垫，局面已经结算 | 错过唯一时点 |
| **F5** | **被反攻心**：你的在意点被对手读出 | 对方开始提起"那个人/那件事" | 你从攻方变守方 |
| **F6** | **把表演当信息**：误读对手的示弱/愤怒 | 你按"他怕了"行动，结果他早就准备好 | 落入反向嵌套（P3-F3） |
| **F7** | **对内失效**：只攻外不攻内 | 队友开始私下做最优选择 | 内部先崩（第278章囚徒困境） |
| **F8** | **伦理/合规越界** | 手法依赖真实伤害、威胁、胁迫 | 失去授权与合法性；对真实个人造成心理伤害不可接受 |

## 6. 反制手段（当对手在攻你的心）

### 六道防火墙

1. **冷却期**：任何在压力下做出的决定，强制延迟一个回合 / 一段时间。**"我现在不做决定"是最强的反攻心句。**
2. **强制二次校验（识破即被骗）**：
   - 写下"我看穿了什么"；
   - 问"这一层是谁希望我看穿的"；
   - 找一个**在两种情况下都安全**的动作（占优策略），而不是"反着来"。
3. **退出成本量化**：把"我已经投入多少"写成**数字**。情绪无法对抗算术。
4. **情绪触发清单**：预先写下"当我感到被激怒/被捧/被催促时，我不做决定"。**知道自己何时会失控，是最便宜的盔甲。**
5. **拆解框架**：拒绝在对方给的选项里选。**主动提出第三个选项**（P3-6.5）。谁定义选项，谁赢。
6. **把决定外包给机制**：用队伍投票、书面标准、预设规则代替临场判断（尤其在时间压力下）。

### 专项反制
- **对沉没成本**：问"如果我今天第一次遇到这件事，我还会投吗？"（重置视角）
- **对逼退博弈**：把死线**重新谈判**或让死线对对方也生效（对称化）
- **对平局算输**：拒绝接受对方定义的平局归属（争夺规则权）
- **对囚徒困境**：把单次博弈转成重复博弈（长期合作、声誉、可观测承诺）
- **对元问题**：识别"指涉回答行为"的提问方式，用**"我必须如实回答吗"**这类前置问题打破结构
- **对扮猪吃虎**：不看对方"表现得多笨"，只看**他每次行动的净收益**——行为不会撒谎

### 执念审计（自检，必做）
> 齐夏的最大破绽是他的执念（余念安），且被反复利用。
> **自检三问**：① 我在这件事上，有没有一个"即使损失全局也要保住"的东西？② 对手知道吗？③ 如果他拿它来交换，我的预案是什么？

## 8. 合规边界（必须遵守）

**允许**：谈判博弈、安全红队演练、竞技/桌面推演、公开对抗性场景中的信息差设计、节奏控制、框架争夺。

**禁止**：对真实个人实施胁迫、威胁、心理伤害、PUA、伪造证据陷害、诱导自伤或自杀（原书合同中的"请马上自杀"条款是**反面教材**，不是可复用工具）。

**判断标准**：如果你的方案在对方**完全知情**后仍然有效，它是"设计"；如果只在对方**被蒙蔽且受到实质伤害**时有效，它是"侵害"。

## 9. 与其他模式的接口

- ← **P1**：画像证据来自规则侦察与观察通道。
- ← **P2**：假规则与隐藏规则负责提供"情绪事件"（意外、损失、机会）。
- ← **P4**：承诺装置负责让情绪结果**不可撤回**（否则对方冷静后全部复原）。
- → **P3**：攻心常用于掩护层间切换（在对手情绪波动最大的瞬间换棋盘）。
- → **i003**：本模式对应**行为博弈**与**信号博弈**——情绪是"低成本高信息"的信号载体，
  而"识破即被骗"对应**高阶信念（higher-order beliefs）**的操纵。
