# 例 1 · 用方法论证库拆解「极乐钱庄」

> 目的：演示 agent 如何把 P1→P3→P4→P5 跑成一条**可执行的决策链**，而不是只读故事。
> 标注：`[确认]` = 词条原文可查；`[推导]` = 我方基于规则的计算/推断，非原书明述。

---

## 0. 输入

- 场景：地羊（白羊=齐夏）开设的「极乐钱庄」，三层：博彩 / 彩券 / 存款。`[确认]`
- 你是参与者，手握有限「道」，目标是**净收益最大化**（不是"玩得开心"）。

---

## 1. P1 · 规则卡（节选）

| 项 | 原文要点 `[确认]` | 未定义/可利用处 `[推导]` |
|---|---|---|
| 第一层 博彩 | 押「胜/负/杀」；押「杀」获胜由白羊赔付桌面双倍；胜者付一颗道场地费，**只赢一颗则不收** | ①"只赢一颗"→ 拆单免佣；②「杀」的概率极低但**你可亲手制造**（杀死生肖）→ 内幕化 |
| 第二层 彩券 | 1 道/张，自选 12 字（红/绿/白），日落开奖；与屏幕重合者取走全部筹码；无人重合则**滚入奖池**，次日须重买 | 样本空间 3¹²=**531441** → 命中率上限 1.9e-6；滚池筹码属于"未来的买家"，不自动属于你 |
| 第三层 存款 | 存款挂生肖名；该生肖十日总结「总红」+10%、「总绿」−10%、「总白」不变，随轮回可取 | 存款是**杠杆化的方向押注**；与第一层押注可反向对冲 |
| 供给结构 | 被赌死的生肖由"距离第二近"的同类接替 | 供给端可预判 → 可提前布局下一轮标的 |
| 结算层 | 第十天轮回前一小时做「总评」（总结的总结） | 真正的结账时点：在此之前的一切都是"未实现收益" |

**判定函数**：三层共享同一随机源——「生肖与参与者的对局结果（红/绿/白灯）」。`[确认]`
**结论（P1 输出）**：这是一张"**同一个随机变量、三种定价方式**"的桌子 → 套利存在与否，取决于三者对同一变量的**定价是否一致**。

---

## 2. P3 · 分层：哪一层是真战场

| 层 | 内容 | 判断 |
|---|---|---|
| B 诱饵层 | 第一层博彩（声光效果最强、可即时结算） | 对手（其他参与者）的注意力都在这里 |
| O 观察层 | 博彩的下注分布 → 众人对"哪个生肖会赢"的私人判断 | 免费情报 |
| S 牺牲层 | 小额博彩下注（输掉也不影响本金） | 用 1 道的"只赢一颗"免佣额度当门票 |
| C 承载层 | 第三层存款（±10% 十日杠杆） | 真正的收益在这里，且**不需要预测单场胜负**，只需要方向统计 |
| T 结算层 | 第十天前一小时的「总评」 | 在此之前必须完成对冲 |

**切换时点**：总评前一轮（留出取款与对冲的操作时间）。

---

## 3. 定量决策（P1-S3 + P3-S3）

### 3.1 彩券要不要买？—— 不要

- 样本空间：3¹² = **531 441**。`[推导]`
- 单张命中概率上限 ≈ **1.88×10⁻⁶**。
- 若当前有 N 张他人彩券（单张 1 道），命中即得 N 道（毛收益），则
  `EV ≈ (N / 531441) − 1` 道。
- 要让它为正，需要 `N > 531 441` 张他人彩券——即奖池需超过 53 万道。`[推导]`
- **唯一转正路径**：你**能影响开奖结果**（即能影响红/绿灯的统计）→ 这属于"内幕 + 操纵"，也是白羊（庄家）才有的位置。
- **结论**：作为普通参与者，彩券是负 EV 陷阱；它的功能是**制造沉没成本**（每天重买，P5-S3）。

### 3.2 押「杀」是不是好买卖？—— 取决于你是否能制造「杀」

- 押「杀」赔付双倍（+2 倍桌面），但「杀」= 该生肖死亡，属于极低概率事件。`[确认]`
- 若 `P(杀) < 1/3`，则押「杀」的期望收益为负。`[推导]`
- 但**「杀」的触发权在人手里**（可以真的去杀生肖）→ 一旦你有能力实现该事件，
  赔率就从"彩票"变成"内幕交易"。这是第一层唯一真正的正 EV。
- 风险提示：这也正是庄家的**诱饵设计**——用双倍赔率把筹码吸到低概率事件上。

### 3.3 存款 ±10% 的正确用法

- 存款 X 到生肖 A：若 A 的十日总结为「总红」→ +0.1X；「总绿」→ −0.1X；「总白」→ 0。`[确认]`
- 单场结果随机，但**十日统计量**比单场稳定得多（大数定律）→ 存款的风险远低于单场博彩。`[推导]`
- **对冲结构**：在第三层押"方向"，在第一层用小额押反向（押其"负"），
  两端收益负相关 → 把"预测问题"降级为"波动管理问题"。
- 注意「总白」= 平局/死亡/无人参与的兜底：**死亡越多，收益越可能归零** → 与"押杀"策略天然冲突，不可同时使用。`[推导]`

## 4. P4 · 把它变成一份可执行的对赌（给自己用）

| 七要素 | 内容 |
|---|---|
| ① 标的 | 十日结束时的「总红/总绿/总白」 |
| ② 对手 | 庄家（白羊）/ 其他参与者 |
| ③ 判定函数 | 屏幕总评（客观设备）→ **裁决者对我有利**（不是对手口头解释） |
| ④ 筹码 | 只用"可承受损失额度"的存款额度，绝不用全部身家 |
| ⑤ 时间边界 | 第十天总评前一小时为截止，**在此之前可取款**（有退出权） |
| ⑥ 制裁 | 最大损失 = 存款额的 10%（可量化、可承受）→ 这是**不对称赌局**（上限已知） |
| ⑦ 裁决者 | 因果回响驱动的显示屏（无解释空间） |

**结论**：第三层是全场**唯一"损失上限已知、判定客观、可随时退出"**的博弈 → 主力资金应当在这里，
而不是在"看起来最刺激"的博彩层。

---

## 5. P5 · 反攻心（识别庄家的设计）

| 庄家手法 | 机制 | 反制 |
|---|---|---|
| 押「杀」双倍 | 用高赔率吸引筹码到低概率事件 | 先算 `P(杀)`，算不清就不下注 |
| 彩券每日重买 + 滚池 | 沉没成本 + "奖池在长大"的错觉 | 记住：滚池属于**未来的买家**，不自动属于你 |
| 场地费"只赢一颗不收" | 小额免佣 → 鼓励频繁下注 | 把它当**免费探针额度**，而不是"多玩的理由" |
| 即时结算（博彩）vs 十日结算（存款） | 即时反馈让人上瘾，长期结构被忽略 | 主动把注意力移到**结算时点最远的那一层** |
| 声光最强的第一层 | 注意力诱饵 | 用 P3 的"读不在意"：**庄家最不在意你玩哪层，哪层就是陷阱** |

---

## 6. 一页决策清单（可直接复用为模板）

```
[ ] 三层是否共享同一随机源？→ 是 → 找定价不一致处
[ ] 每层的期望值是多少？算不清的那一层不下注
[ ] 哪一层的损失上限已知且可退出？→ 主力资金放这里
[ ] 哪一层的"刺激度"最高？→ 那层是诱饵，只用免佣额度
[ ] 我是否有能力影响"开奖结果"？没有 → 彩券一律不买
[ ] 结算时点在哪？→ 在此之前完成对冲
[ ] 我的最大损失是多少？写下来；超过承受阈值就砍仓位
```

---

## 7. 本案例抽象出的三条通用结论

1. **同一随机源的多重定价 = 结构性套利**：先找"哪个变量被定价了三次"，再看三次定价是否一致。
2. **佣金门槛与滚池是最容易被忽略的免费收益/免费陷阱**：前者可用于拆单，后者专门制造沉没成本。
3. **损失上限已知的博弈 > 刺激度高的博弈**：在有杠杆的桌面上，"能活到结算"本身就是优势。
