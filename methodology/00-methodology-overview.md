# 谋略方法论总纲（齐夏 skills · 核心方法论章节）

> 本目录是 `齐夏 skills` 的**方法论层**：不做剧情复述，只做"可被 agent 调用的谋略动作"。
> 所有模式均从已确认案例（极乐钱庄、朔望月、仓颉棋、两军问题、真假话问询、生肖飞升对赌合同等）反向抽象，
> 每个模式都给出 **触发条件 / 执行步骤 / 失败条件 / 反制手段** 四要素，并附原书锚点。

---

## 0. 一句话内核

**齐夏的一切胜利，都来自"比对手多看见一层规则"，然后把这一层认知差兑换成不可逆的优势。**
他不是"更会赌"，而是"先弄清这张桌子上到底有几套规则、谁定的、谁必须遵守、谁有权不遵守"，再设计一个**对方赢了也没用、输了就必死**的局。

由此得到谋略的第一性原理（三差模型）：

| 差 | 定义 | 变现方式 | 本书代表 |
|---|---|---|---|
| **信息差** | 对方的私有信息 / 未知规则 / 未知动机 | 定价权、先手权、诱骗对方下注 | 朔望月隐藏规则「点数不得大于十六」 |
| **规则差** | 规则未定义处、规则允许的"合法作恶"、谁能改规则 | 把不确定性转成对方的必然损失 | 隐藏规则权限：羊可欺诈、猴可作弊、兔可破坏 |
| **承诺差** | 谁的行为不可逆、谁的成本已沉没、谁敢押命 | 让对方自己走进死角 | 仓颉棋「拒令即溃逃之将，当场抹杀」 |

三差之外还有**元层**：目标本身可能是别人塞给你的谎言（第337章「道的骗局」——集齐"道"不是出路，反而招来洗牌）。**不质疑目标函数的人，越努力越接近陷阱。**

## 1. 五层拆解模型（任何"局"都可以按此解剖）

```
L1 认知层：桌上有什么信息？谁掌握什么？谁能观测谁？（明牌/暗牌/公共牌/屏幕/广播）
L2 规则层：规则全文是否公开？未提及处是什么？谁有"隐藏规则"权限？规则能否被改？改的门槛？
L3 承诺层：哪些动作不可逆？谁的血已押上桌？退出的成本是多少？失败判定函数是什么？
L4 心理层：对方的恐惧、贪婪、羞耻、执念是什么？哪一句话能让他"自己说服自己"？
L5 元层 ：这个目标是谁定的？赢了之后会发生什么？终局由谁结算？
```

**agent 使用规则**：进入任何新环境先做 L1→L2 的侦察（模式 P1），再做 L3 的承诺结构设计（P4），
L4/L5 是放大器与保险丝（P5 / 反问目标）。**跳层操作是新手最常见的死法**——没有 L1 信息就去 P5 心理战，等于送。

## 2. 谋略八问（进入未知局的强制 checklist）

1. **规则全文在哪？** 我拿到的是摘要、口头转述，还是原文？（"广播传递的规则"≠"张贴的规则"）
2. **哪些词没有被定义？** 谁负责解释？"甲方拥有最终解释权"这类条款在谁手里？
3. **谁是裁判，裁判的激励是什么？** 裁判是否也是参与者？（四情扇：地羊在本局属"参与者"）
4. **赢的判定函数是什么？** 是"杀死"、"最多"、"最接近"、"不掉下去"，还是"存活"？（判定函数比策略更值钱）
5. **输的代价由谁承担？** 是我、我的队友、还是我根本没见过的人（第三方赌约）？
6. **我有没有"合法的无成本动作"？** 不动即平衡（跷跷板）、小注免佣（极乐钱庄）、任务物被销毁则义务解除（送信人粉碎机）。
7. **我能否只赢半步？** 让对方"以为自己看穿了"，比让他"一无所知"更有杀伤（识破即被骗）。
8. **赢了之后，结算方会做什么？** 谁能在结算层改写胜负（规则更改、第三方赌约、抹杀裁判）？

> 只要第 1、4、8 问没有确定答案，**不要下第一笔注**。

| **P4** | 对赌与承诺设计 | 怎么把口头约定变成对方无法反悔的锁？ | 高 | `04-bets-commitment.md` |
| **P5** | 心理战与攻心 | 怎么让对方在理性上明明能赢，却选择自毁？ | 高 | `05-psych-warfare.md` |

### 情境 → 模式 路由

| 你观察到的情境 | 首选模式 | 组合 |
|---|---|---|
| 进入新场景 / 只拿到口头规则 / 有"裁判" | P1 | P1→P4 |
| 规则里出现"最终解释权""请立即自杀""分类超出请撕毁" | P2 | P2→P5 |
| 规则公开且对我不利（对手先手、对手资源多） | P2 + P4 | 制造新的可选项 |
| 对手明显比我强，正面对抗必输 | P3 | 设"假目标"让其自耗 |
| 有人向我提出约定、结盟、赌注 | P4（先查判定函数） | P4 的"反制"节 |
| 对手开始犹豫、下注过重、反复确认 | P5 | 沉没成本 + 逼退 |
| 我"看穿了"对方 | **先读 P2 反制节**：识破即被骗 | 强制二次校验 |
| 目标清晰、动力十足、所有人都在收集同一个东西 | **P1 的元层扩展**：目标真实性审查 | 第337章「道的骗局」 |

## 4. 三条铁律（避免把方法论用成自毁说明书）

1. **先算"不做"的收益。** 齐夏多次胜利来自"识别出这是个不必解的死局"（跷跷板不动即胜、彩券无人中奖滚奖池、极乐钱庄只赢一颗不收费）。**行动前先问：有没有一个"什么都不做"就能赢的解？**
2. **任何计划必须有"第二计"。** 第1195章「我有第二计」不是修辞，是结构要求：主计、备用计、脱身计三层缺一不可；只有一计的局叫"赌"，不叫"谋"。
3. **欺骗的合规边界：本方法论用于对抗性博弈、红队演练、谈判与安全评估。对真实世界的人实施欺诈、伤害、胁迫不在支持范围。**对应到 agent 行为，就是：可以设计规则内的施压与信息差，不得伪造证据陷害、不得诱导自伤。

## 6. 使用顺序（agent 默认工作流）

```bash
python3 scripts/pattern_cli.py eight                 # 1. 谋略八问：确认信息缺口
python3 scripts/pattern_cli.py match "<情境描述>"     # 2. 定位主模式
python3 scripts/pattern_cli.py show <P?>             # 3. 读触发条件与执行步骤
python3 scripts/pattern_cli.py premortem <P?>        # 4. 事前验尸：先排失败条件
python3 scripts/pattern_cli.py check <P?>            # 5. 作为执行清单逐项打勾
python3 scripts/validate.py                          # 6. 确认引用真实存在（0 错误 0 警告）
```

> 顺序不可颠倒：**先八问、再定模式、再验尸、最后执行**。
> 直接跳到"执行步骤"是最常见的失败起点（因为它看起来最像"答案"）。
