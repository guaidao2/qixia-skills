## 通用约定（所有模板共享）

1. **先路由，再深入**：任何模板都从 `python3 qixia.py ask "<情境>"` 或 `route … --json` 开始，不许跳过。
2. **路径**：`{{PACK_ROOT}}` 指 `qixia.py` 所在目录；所有命令在该目录下执行，或显式加 `cd {{PACK_ROOT}}`。
3. **不许编造**：模型参数若原文没给，必须标注"建模假设"，并给出基准/悲观/乐观三值。
4. **不许省略失败条件**：任何结论必须附 `fail_if`，否则视为未完成。
5. **合规**：仅用于对抗性博弈、谈判、红队演练与规则审计；不得用于对真实个人实施欺诈、胁迫或诱导自伤。

## 最短可用（不想挑模板时）

```text
在 {{PACK_ROOT}} 下工作。先运行 `python3 qixia.py ask "<我的情境>" --json` 拿路由，
按返回的 next 命令执行，然后只输出四行：结论 / 依据(关键数字+gaps) / 下一步一个动作 / 该动作的失败条件。
不许复述方法论，不许输出原著剧情。
```
