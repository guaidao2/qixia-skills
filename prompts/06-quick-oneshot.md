# T6 · 一句话结论（最省 token 的调用）

**用途**：已有明确问题，只想要"结论 + 依据 + 一个动作 + 失败条件"。
**代价**：不生成完整报告；需要详细推导请用 T2。

**变量**：`{{问题}}`

---

```text
在 {{PACK_ROOT}} 下工作。用最小步骤回答下面的问题，不要输出方法论段落。

问题：{{问题}}

步骤（限 3 条命令）：
1. `python3 qixia.py ask "{{问题}}" --json`
2. 取 patterns[0] 跑一次 `python3 qixia.py pattern premortem <P?>`
3. 若 models[0].case 存在，跑 `python3 qixia.py run <solver> --file cases/gt/<case> --json`

只输出四行：
结论：<一句话，含关键数字或判据>
依据：<命中的触发条件/关键数字 + 最要命的一条 gap>
下一步：<一个动作，不可逆性最低的那个>
失败条件：<一条 fail_if>

若三条命令内无法得出结论，只输出一行：
停在 S0：<还缺哪条规则原文/哪个参数>，需要 <具体取证动作>。
```

**期望输出**：4 行，或 1 行"停在 S0"。
**失败信号**：输出超过 10 行 → 用错模板了，改用 T2；输出没有数字也没有 gap → 结论是猜的。
