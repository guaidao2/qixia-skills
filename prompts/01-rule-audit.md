# T1 · 规则审计（只找漏洞，不下注）

**用途**：拿到一套规则（合同、守则、游戏说明、平台条款）时，输出"规则卡 + 缺口清单"。
**为什么单独一张**：这是本包**最安全、最高频**的用法——只审计，不采取任何对抗动作。

**变量**
- `{{规则原文}}`：逐字粘贴，不要改写、不要摘要
- `{{裁判}}`：谁解释规则、谁能改规则、他和谁利益一致
- `{{赌注}}`：输了付出什么（钱/命/记忆/队友/资格）

---

```text
在 {{PACK_ROOT}} 下工作。对下面这套规则做一次纯审计，不要给"怎么赢"的建议，只找结构性问题。

规则原文（逐字）：
"""
{{规则原文}}
"""
裁判/解释者：{{裁判}}
赌注/代价：{{赌注}}

执行步骤：
1. 运行 `cd {{PACK_ROOT}} && python3 qixia.py pattern show P1`，按它的 S1–S7 顺序做。
2. 运行 `python3 qixia.py pattern check P1` 作为逐项清单。
3. 若规则涉及分配/奖励/申报/名额，追加运行
   `python3 qixia.py run mechanism --file cases/gt/g4_mechanism_feisheng.json`
   并说明：本规则在哪些地方与那个案例同类。
4. 需要判断"隐藏规则是否存在"时，用 `python3 qixia.py pattern show P2` 的 D1/D2 两节，但只做识别，不做实施。

输出（必须全含，按此顺序）：
A. 规则卡：判定函数 / 平局如何处理 / 时限 / 解释权归属 / 隐藏规则权限 / 违规后果
B. 未定义词清单：每个词 + 谁有权解释 + 解释偏差会造成什么
C. 六类缺口，逐条给证据（引用原文片段）：
   ① 判定函数缺失 ② 未定义词 ③ 裁判激励不相容 ④ 隐藏权限 ⑤ 时限/顺序漏洞 ⑥ 结算/退出缺失
D. 激励审计：说真话划算吗？如果撒谎有正收益，指出具体条款
E. gaps 优先级：按"可被对手用于对付我"的顺序排序，每条给一句反制方向
F. 一句话结论 + 是否存在"不动即胜/合法无成本动作"

禁止：给具体实施话术、假设原文没写的内容、把标题或传闻当成规则事实。
```

**期望输出**：A–F 六段，C 段每一条都带原文引用。
**失败信号**：结论里出现"应该可以""大概算"——说明规则原文没抄全，退回第 1 步。
