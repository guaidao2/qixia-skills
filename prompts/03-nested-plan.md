# T3 · 布局 / 连环计（正面打不过时的分层计划）

**用途**：对手在单一维度碾压我，正面对抗期望为负，需要"让对方在错误层级上做最优决策"。
**前置警告**：P3 危险度为 critical——**没有第二计就不许执行**。

**变量**
- `{{我方劣势}}`：兵/钱/权限/信息/时间，具体到可比较
- `{{对手痛点}}`：他必须回应的事（必须救的人、必须拿的东西、必须守的规则）
- `{{可用筹码}}`：我独有的信息通道、身份、可牺牲资源

---

```text
在 {{PACK_ROOT}} 下工作。设计一套分层布局，但先把"这套局会不会被看穿/会不会拆不掉"算清楚。

我方劣势：{{我方劣势}}
对手必须回应的事：{{对手痛点}}
我独有的东西：{{可用筹码}}

执行步骤：
1. `python3 qixia.py pattern show P3`，按其分层结构（诱饵层/观察层/可牺牲层/承载层/结算层）逐层填。
2. 对每一层，先验证"对手最后一步为什么会照做"：
   `python3 qixia.py run backward --file cases/gt/g6_tree_changjie.json`（参照：第三方执行的威胁才可信）
   若威胁由我自己执行，追加 `python3 qixia.py run backward --file cases/gt/g6b_tree_selfexecute.json`，
   它会示范"不可信威胁"如何让整条链失效。
3. 验证"赢了之后谁结算"：`python3 qixia.py run meta --file cases/gt/g12_meta_dao.json`。
4. 事前验尸：`python3 qixia.py pattern premortem P3`，逐条说明本局是否触发。
5. 若某层依赖对手"继续投入"，用 `python3 qixia.py run sunk --file cases/gt/g7_sunk_250.json` 判断其继续条件。

输出格式：
① 一句话局的结构（谁是诱饵、谁在观察、谁被牺牲、谁承载、谁结算）
② 每层：目标 / 对手在该层的最优反应 / 我的收益 / 该层的失败条件
③ 切换时点：出现什么信号时进入下一层（必须可观测，不能是"感觉"）
④ 第二计：主计失败时的备用计与脱身计（各一句，含触发条件）
⑤ 被看穿预案：对手若识破，他最强的反制是什么，我怎么让"识破"本身变成陷阱
⑥ 层数自检：超过 4 层就说明哪一层可以删——层数越多，自身出错概率越高

禁止：设计超过 4 层；任何一层没有可观测的切换信号；没有脱身计。
```

**失败信号**：写不出"切换信号的观测方式"→ 这不是布局，是赌博。
